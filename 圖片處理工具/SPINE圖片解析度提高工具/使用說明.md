# SPINE圖片解析度提高工具

版本 1.0.2（2026-09-05）

安裝 Python 3 與 Pillow，執行「啟動SPINE圖片解析度提高工具.cmd」。使用內附 Real-ESRGAN 與模型，GPU/Vulkan 相容性依本機環境。輸入資料夾直接一層的 PNG（不包含以 _ 開頭的檔案），輸出 2/3/4 倍 PNG、CSV 報告和預覽。rename 保留同名成果並編號，skip 略過，overwrite 明確覆寫輸出；禁止輸出等於來源。工作根目錄僅容納帶標記的任務子目錄，只清除自己建立的那一個。勾選保留中介檔後，才能在來源/模型/倍率完全相同時使用「只套 alpha」。

本版改善：新增來源/輸出/工作目錄保護，專屬任務目錄與驗證恢復；同名策略、原子PNG發佈及程序樹取消。
