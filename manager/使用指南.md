# 小魚骨頭工作包管理器｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

集中瀏覽、下載、更新與開啟已登錄工具；管理者可維護工具資訊與 Git 提交。工具本體、引擎插件與管理器本體是不同更新層次。

## 環境與啟動

Windows。取得 `ToolkitManager.zip` 後完整解壓到可寫資料夾，開 `ToolkitManager.exe`；不能只複製 EXE，旁邊 `_internal` 必須保留。開發執行及打包見 README。

## 操作步驟

1. 在設定核對 Owner=`missingfish1234`、Repo=`slot-toolkit`、Branch=`main`，並選工具安裝位置。
2. 按重新整理，選分類／工具，閱讀說明後下載或更新；有入口可開啟，資源型工具使用「資料夾」。
3. Cocos／Unity／PS 插件下載後，仍依各指南安裝進對應引擎；下載完成不代表正式專案副本已換版。
4. 管理器本體用「管理器更新」；日常工具更新則選各工具處理，兩者不要混淆。

## 輸出與保存

本體資料夾保留 config.json，工具下載到設定的安裝根；工具與管理器的更新會保留完整舊版備份。不要將含 Token 的個人設定放進分享包／Git。

## 常見問題與限制

- 只列出 tools-index.json 已登錄工具；原始碼在 Git 不代表管理器一定出現。例如新 Unity Prefab 工具目前未登錄。
- 離線索引僅能顯示已同步資訊；首次下載仍需網路。HTTP 403 額度用完請稍後重試或自行設定 Token。
- SHA 校驗失敗請重整／重試，不要略過校驗手動覆蓋正式安裝。
- 舊 1.1.x 首次跨版建議解壓新版到新資料夾，確認能開啟後再搬設定，保留舊版。
- 管理者密碼只是防誤操作，不是 GitHub 權限；有 Git 權限才能推送。

## 驗收檢查

重開管理器確認設定與工具清單；先更新一個工具，再確認入口、個人檔案及備份保留。
