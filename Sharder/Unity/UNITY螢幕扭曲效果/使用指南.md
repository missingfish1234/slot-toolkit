# Unity 可定位螢幕扭曲效果｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

用場景中的 Renderer／Quad 在指定位置對已繪製背景做扭曲，適合衝擊波等局部畫面效果。

## 環境與啟動

Unity 6.3 Built-in；Shader 使用 GrabPass。匯入 `PrefabScreenDistortion_BuiltIn.shader` 與 `PrefabScreenDistortionController.cs`，不是 URP Renderer Feature。

## 操作步驟

1. 建立 Quad + Renderer，建立 Shader 為 `Custom/Prefab/Screen Distortion BuiltIn` 的材質並套用。
2. 掛 Controller，指定 Target Camera 與 Target Renderer，確認相機看得到該物件。
3. 先用 strength=0.25、radius=0.25、feather=0.08、opacity=1，移動 Quad 檢查背景扭曲，再調強度與尺寸。

## 輸出與保存

保存材質、控制器及 Prefab。控制器以 MaterialPropertyBlock 寫入參數，不產生新背景圖。

## 常見問題與限制

- 扭曲沒效果先確認 Built-in、背景已先繪製、相機／Renderer 引用與不透明度。
- GrabPass 需要先有可取樣的畫面；Render Queue／相機配置會影響結果。
- URP／HDRP 沒有本工具對應實作；需另行移植，不能直接改 Shader 名稱使用。

## 驗收檢查

用有明顯線條的背景測強度 0 與非零的差異，再測相機移動及實際演出排序。
