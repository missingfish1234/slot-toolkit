# Unity 彩虹 Shader｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

為 UGUI／BMFont 圖文字元提供彩虹、掃光、描邊與美術材質面板，支援每字或整串連續的流動座標。

## 環境與啟動

Unity 6.3 + UGUI。匯入 `BMFont_Rainbow_OptimizedArtistPanel.shader`、`BMFontUv2Filler.cs` 及 `Editor` 面板腳本；Editor 子資料夾需保留，別混用 Old 版本。

## 操作步驟

1. 建立材質，Shader 選 `Custom/BMFont_Rainbow_OptimizedArtistPanel`，指派給目標 UGUI 圖文元件。
2. 先用美術面板的快速預設；要保留原圖選「疊加／保留原圖」，再調彩虹強度、速度與閃爍。
3. 需要 BMFont 座標同步時，在圖文字元物件掛 BMFontUv2Filler，確認 Canvas 有 TexCoord1／TexCoord2。
4. 以 GlobalUV 測整串連續，LocalUV 測每字重複。粒子用途先選粒子安全設定，不沿用字型 UV 模式。

## 輸出與保存

保存材質、UV 元件與 Canvas 設定；不輸出新字型。

## 常見問題與限制

- UV Filler 以每字四頂點 Quad 為前提，不保證任意 TMP／MeshEffect 拓樸。
- UV1／UV2 缺失可能造成每字顏色不連續；元件會補通道，仍需確認實際 Canvas。
- 粒子藍色段變黑時先核對粒子模式及原圖顏色混合；不要一開始只加大亮度。

## 驗收檢查

測數字、標點、最長字串、Local／Global 模式及粒子安全預設；使用目標裝置確認畫面和成本。
