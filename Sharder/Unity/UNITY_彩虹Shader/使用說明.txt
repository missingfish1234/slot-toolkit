
BMFontRainbowArtistShaderGUI.cs 丟入專案內可以用美術面板控制彩虹 Shader

如果希望保留圖片本身內容，只做彩虹疊光：
在「彩虹填色」裡把「彩虹混合模式」改成「疊加 / 保留原圖」
再用「彩虹疊加強度」控制彩虹覆蓋量
也可以直接按快速預設「圖片疊光」

如果希望彩虹流動時有閃白/閃色：
在「彩虹填色」裡開啟「啟用彩虹閃爍」
用「閃爍頻率」控制每秒閃幾次
用「閃爍顏色」選白色或其他顏色
用「閃爍強度」控制閃爍明顯程度

如果只想提高藍色亮度，其他色相不變：
在「彩虹填色」裡調高「藍色亮度倍率」
如果藍色已經接近純藍但仍然偏暗，調高「藍色補光」
「藍色影響範圍」越大，越多青藍/紫藍會一起被提高
一般建議先用 1.2～1.5 倍，範圍維持 0.16

如果用在 Particle 粒子圈，藍色段看起來變黑：
按快速預設「粒子安全」
或手動設定：
「基本設定」→「乘上原圖顏色」設為 0
「基本設定」→ 開啟「粒子模式 / 忽略 UV1 UV2」
「彩虹填色」→「粒子軟邊填色」設為 1
「彩虹填色」→「藍色亮度倍率」約 1.6～2.0
「彩虹填色」→「藍色補光」約 0.35～0.55

如果希望每個數字顏色同步
需要在顯示 BMFont 數字的 UI 物件掛上 BMFontUv2Filler.cs

BMFontUv2Filler 會寫入：
uv1 = 每個字自己的 Local 0~1 座標
uv2 = 整串文字的 Global 0~1 座標

並在鏡頭 Canvas 的設定上打開 TexCoord1 與 TexCoord2
到「顯示這串 BMFont 數字的那個 Canvas」上：

Canvas → Additional Shader Channels

勾選 TexCoord1

勾選 TexCoord2

材質面板建議：
「填色群組」選每物件/每字
「每物件座標」選整串連續 GlobalUV，可讓整串文字接成一條連續彩虹
「每物件座標」選每字重複 LocalUV，則每個字各自跑完整彩虹
