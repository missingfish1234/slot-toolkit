# Unity63_DarkCenterEdgeGlow

版本 1.0.1（2026-09-05）

Unity UGUI 壓暗中心、發亮輪廓與扭曲特效。

Unity 6.3 與 UGUI，匯入 Shader、建立材質套 Image。Lightweight 可降低輪廓取樣；關閉維持舊效果。請以獨立貼圖或有足夠 padding 的 Atlas 驗證邊緣，尚不宣稱所有 SRP／裝置均相容。

本次更新：新增可選 4 方向 Lightweight 模式；預設仍為完整 8 方向效果。
