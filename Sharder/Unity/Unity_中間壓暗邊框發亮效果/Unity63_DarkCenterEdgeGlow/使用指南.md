# Unity 中心壓暗與輪廓發光｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

對透明文字／圖騰 PNG 加上中心壓暗、輪廓亮邊、外光與噪聲扭曲。適合少量標題 UI。

## 環境與啟動

Unity 6.3、Built-in、UGUI。匯入 Shader 與 Noise PNG，建立材質，Shader 選 `Ark/UI/Dark Center Self Contour Glow Distortion`，指派給 Image／RawImage。

## 操作步驟

1. 指定 `Noise_Seamless_256.png`，Noise 使用 Repeat、Bilinear，先以非色彩資料方式設定。
2. 先調 Center Color／Keep Source RGB，確認壓暗範圍，再調亮邊顏色、寬度與強度。
3. 逐步加入外光、Noise Distortion 與波紋。圖騰周圍預留透明空間，必要時增加畫布。
4. 有效能需求再比較 Lightweight 的四方向取樣與預設完整八方向效果。

## 輸出與保存

保存材質與貼圖引用；效果只在 UI 繪製範圍內，不會自動擴大原 PNG 畫布。

## 常見問題與限制

- 外光被切掉先檢查透明留白及 Mask／RectMask2D。
- 圖集邊緣混到別圖需增加 padding 或改獨立貼圖測試。
- 真正大範圍 Bloom 需另外的相機／後處理；HDR 顏色數值不保證所有管線有 Bloom。
- 多重取樣有成本，不宜直接套滿整盤所有圖騰；URP／HDRP 未在此說明中保證。

## 驗收檢查

用目標背景、最小／最大 UI 尺寸檢查亮邊、裁切與透明度，並在目標裝置量測成本。
