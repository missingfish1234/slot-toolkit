# Unity 全畫面閃光殘影｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

在相機輸出上混合歷史畫面，做起爆、爆發與收尾三段式殘影演出。

## 環境與啟動

Unity 6.3 Built-in；使用 OnRenderImage，不適用直接掛入 URP／HDRP。匯入本層 Shader 與控制腳本。

## 操作步驟

1. 在實際輸出 Camera 掛 FullScreenAfterimageEffect，指定使用 `Hidden/FullScreenAfterimageOctoBuiltIn` 的材質。
2. 在相機或管理物件掛 AfterimageEffectController，Target Effect 指向同一個效果元件。
3. 選預設與三段時間，進入 Play Mode 呼叫 `PlayPresetSequence()`，先確認整體節奏。
4. 需要 Animation Event 時在動畫物件掛 AfterimageAnimEventProxy，呼叫 `Anim_PlayPresetSequence`／`Anim_StopAfterimage`。Prefab 自主控制可另用 AfterimageEffectProxyV2，不要混用多個控制器搶寫。

## 輸出與保存

保存 Camera、控制器、材質與動畫事件；效果執行時產生歷史貼圖，不是可交付的錄影檔。

## 常見問題與限制

- 舊說明中的 Anim_PlayOctoSequence 並非目前代理的入口；以本指南與實際程式為準。
- 時間型效果必須在 Play Mode 驗證，編輯預覽不能判定殘影節奏。
- 畫面太亮／髒先降低白閃、亮部增強與歷史保留；結束時 Stop 並按需要清除 History。
- History Downsample=1 為全尺寸，2／4 可降成本；來源 HDR 格式與目標裝置需一起測。

## 驗收檢查

連續播放兩次，再停止，確認沒有上一段殘影殘留；核對 UI 是否需要另相機或後繪製避開效果。
