# Unity 滾分測試工具｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

在 Unity 內用文字、Sprite／BMFont 圖片行或數字輪帶測滾分節奏，支援多種字元來源。

## 環境與啟動

Unity 6.3 + UGUI／TMP，完整匯入 Runtime 與 Editor。Canvas 下建立測試物件，新增「Slot Tools → Number Roller → Robust Number Roller v4」。

## 操作步驟

1. 選 Display Mode；想逐位滾動先選 ImageOdometer。指定 imageRoot 與 Glyph Source。
2. 若用 UGUI_IMAGE 字典，拖入字型 Prefab／Component，按「從 UGUI_IMAGE 字典抽出到 Direct Sprites」，再核對 0–9 與標點。
3. 按「重建顯示」，設定起始／目標數值。DurationSmooth 按時間、UnitsPerSecond 按速度、StepPerTick 按每次增量。
4. 進入 Play Mode 按「播放滾分」。一分一分模式可先用 Points Per Tick=1、Tick Interval=0.005–0.02，開 Odometer Follows Current Value。

## 輸出與保存

保存場景／Prefab 上的工具設定及字型引用；工具生成的顯示子物件有 NumberRollerGeneratedNode 標記。

## 常見問題與限制

- BMFont 目前支援單頁 PNG。UGUI_IMAGE 反射字典需欄位結構相容，抽取後務必逐字檢查。
- 不要把自訂子物件手動標為工具生成節點；工具只管理自己的標記節點。
- 字型引用切換會更新快取；外部程式原地修改同一字型內容時要呼叫 `RebuildDisplay()`。

## 驗收檢查

測 9→10、99→100、長字串、標點及停止到終值；重建與切字型後檢查顯示是否一致。
