# Unity Spine SkeletonGraphic 遮罩｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

用圖片通道與柔邊矩形控制 SkeletonGraphic 的可見範圍，支援遮罩平移、平面旋轉及縮放。

## 環境與啟動

Unity 6.3 + Spine-Unity。一起匯入 `SpineSkeletonGraphicMask.shader` 與 `SpineSkeletonGraphicMaskDriver.cs`。

## 操作步驟

1. 在 Canvas 內建立 MaskArea（RectTransform）及要遮罩的 SkeletonGraphic。
2. 在 SkeletonGraphic 物件掛 Driver，指定 Mask Rect Transform、Mask Texture 與 Mask Shader：`Custom/Spine/SkeletonGraphic Alpha Mask`。
3. 透明圖選 Alpha 通道，無透明的黑白圖選 Red；先關 Invert、開 Use Rect Clamp，Softness 先從小值測。
4. 移動／旋轉 MaskArea 調整範圍，確認後保存 Prefab。

## 輸出與保存

保存 Shader、遮罩 PNG、Driver 與場景綁定，不會裁掉原 Spine 貼圖。停用 Driver 會還原原材質。

## 常見問題與限制

- 白色遮罩全部顯示、黑色／透明隱藏的效果需搭配正確通道；全不見先檢查通道與矩形位置。
- 遮罩貼圖使用 Clamp，避免邊界重複；需要柔邊先確認素材 Alpha。
- 此版主要針對單材質 SkeletonGraphic，多頁／多材質需另行驗收，Shader 與 Driver 不能只更新一個。

## 驗收檢查

檢查移動、45 度旋轉、縮放、反向與停用還原；角色所有動作均需確認不會意外裁切。
