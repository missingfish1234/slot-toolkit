# Unity 多模式溶解 Shader｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

為 UGUI／Renderer／Spine 材質提供噪聲、線性、放射、環形、螺旋及條紋等溶解效果，並可控制進度與邊緣光。

## 環境與啟動

Unity 6.3。匯入 `UI_Spine_Dissolve_MultiMode.shader` 與 ArkDissolve 控制腳本；建立 Shader 為 `ArkGame/UI-Spine/Dissolve Multi Mode` 的材質。

## 操作步驟

1. 將材質指派給目標 Graphic／Renderer，掛 ArkDissolveController；必要時手動指定 Target Material。
2. 先用 Dissolve Amount 測 0→1，再選模式、方向／中心及邊緣光。Noise Texture 使用灰階噪聲。
3. 用 `PlayDissolveOnce()` 或 `PlayDissolvePingPong()` 測試；`StopPreview()` 停止預覽。程式可用 `SetDissolve(value)` 控制。
4. 需要啟用即播放時使用 ArkDissolveAutoPlayOnEnable，保存設定前停止自動預覽。

## 輸出與保存

保存材質、控制腳本與場景／Prefab。只改繪製效果，不會修改 Spine 原始動畫。

## 常見問題與限制

- Instance Material On Play 預設隔離執行期材質；關閉時會改共享材質，可能影響多個物件。
- 編輯預覽仍可改指定材質，重要材質先複製。
- 半透明 Spine、PMA 與多材質使用需在實際專案驗收，不能只用一般 Image 測過就視為全部相容。

## 驗收檢查

測 0、0.5、1 及反向模式，連續啟停多次，確認停用後材質還原及未影響其他物件。
