# Unity_溶解SHARDER

版本 1.0.1（2026-09-05）

Unity UGUI／Renderer／Spine 的多模式溶解與播放控制。

Unity 6.3 匯入 Shader 與控制腳本，將材質套 Graphic 或 Renderer。Instance Material On Play 預設隔離；關閉表示有意修改共享材質。編輯預覽仍可修改指定材質，重要材質請先複製。

本次更新：自建執行期材質明確追蹤所有權，停用／銷毀还原原材質並回收。
