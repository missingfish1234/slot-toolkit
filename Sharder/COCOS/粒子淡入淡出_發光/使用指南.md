# Cocos 粒子淡入淡出與發光｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

利用粒子 Alpha 變化推算生命進度，再控制淡入、淡出及加亮。對象為 ParticleSystem2D。

## 環境與啟動

Creator 3.8。匯入 `ParticleGlow.effect.effect` 並建立材質；檔名的雙 effect 是現有檔名，不要誤找成另一個檔案。

## 操作步驟

1. 將材質指派給 ParticleSystem2D 的 Custom Material。
2. Start Color 的 Alpha 設 255、End Color 的 Alpha 設 0，先避免 Alpha 隨機差異。
3. 材質 fadeParams 可先設 `[0.1, 0.7, 1.5, 0]`：X 淡入結束、Y 淡出開始、Z 發光強度、W 保留。
4. startTint／endTint 先設白色；需疊加發光時將 BlendDst 設 ONE，再微調顏色與亮度。

## 輸出與保存

保存粒子 Prefab 與材質設定，原粒子貼圖不變。

## 常見問題與限制

- 生命節奏不對先檢查粒子 Alpha 是否真的從 255 變到 0；父層透明度也可能影響視覺。
- X／Y 使用 0–1 並讓淡入結束早於淡出開始，避免難以判讀的設定。
- 疊加太亮時降低 Z 與粒子數；這不是 Camera Bloom。

## 驗收檢查

觀察單顆粒子從出生到消失，再測整組重疊與深／淺背景，確認末端不突切。
