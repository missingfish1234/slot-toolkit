# 工具使用總覽

本機文件整理日期：2026-10-08。共 **31 項工具 + 1 個管理器**；包含工具索引的 30 項與另外已提交 Git 的 Unity Spine Prefab 工具。歷史版、相容副本、測試樣本及研發分支不重複列為新工具。

## 第一次使用

1. 先完整解壓工具資料夾，不要只複製 EXE／HTML；vendor、Runtime、Editor 及插件 dist 等相依檔需保留。
2. 找下方對應指南，核對環境與版本，使用一份素材／專案副本先測試。
3. 依指南操作並完成驗收檢查後，才處理正式素材；輸出請與來源分開。
4. 對引擎插件而言，下載和安裝是兩步：還要安裝到 Unity／Cocos／Photoshop，並確認編譯／啟用成功。

## 共通問題

- **雙擊沒反應**：核對是否完整解壓、入口檔是否正確，以及 Python／Node／引擎相依元件是否齊全。Shader 本身不是可雙擊執行的程式。
- **舊結果還在**：先看輸出資料夾、同名策略和所安裝版本；不要只依網頁標題中的舊版本字樣判斷。
- **瀏覽器沒有下載**：查看下載提示或儲存對話框；錄製保持分頁前景，大量圖片改分批。
- **引擎內不正常**：提供引擎版號、工具版本、安裝路徑、Console 錯誤與最小可重現素材；不要直接刪 .meta 或正式檔案。
- **想還原**：先關閉工具，保留新舊成果，再依該工具備份規則恢復；不要刪除不確定用途的 backup／stage／工作資料夾。
