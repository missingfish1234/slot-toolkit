🎰 老虎機模擬編輯器 (Slot Editor v42.4) 使用手冊


1. 簡介
本工具是一個免程式碼的老虎機原型設計工具，專為遊戲企劃與美術設計師開發。 核心功能：

快速搭建老虎機盤面（Reels & Rows）。

配置並預覽橫向轉輪（Top Horizontal Reel）。

調整圖騰權重、尺寸與特殊屬性（Wild/Scatter）。

即時調試動態效果（速度、回彈、掉落消除）。

模擬 Base Game 與 Free Game 流程。



2. 介面概覽

編輯器主要分為三個區域：

頂部工具列 (Top Bar)：全域視圖控制（縮放、隱藏輔助線）。

左側控制面板 (Sidebar)：所有參數設定的核心區域，分為四個分頁。

中央舞台 (Stage)：遊戲畫面的即時預覽區，支援滑鼠拖曳移動視角。




3. 快速上手流程
第一步：基礎佈局 (📐 佈局分頁)
在此設定遊戲的骨架結構。


遊戲結構：

轉輪數 (Cols)：設定直向轉輪的數量（例如 5 輪）。

行數 (Rows)：設定每輪顯示的符號數量（例如 6 行）。

間距 (Gap)：符號之間的縫隙。

橫向轉輪 (Top Reel)： (v42.0 新增功能)

啟用 (Enable)：勾選後會在主盤面上方開啟一條橫向轉動的軌道（常見於 Megaways 玩法）。

橫向格數：設定橫條有幾格。


轉動方向：

RTL (右往左)：符號從右邊出現，往左移動。

LTR (左往右)：符號從左邊出現，往右移動。

XY 偏移：調整橫向轉輪相對於主盤的位置。

格子尺寸：設定單個符號的寬高。點擊 「📐 智能填滿」 可根據遮罩大小自動計算最佳格子尺寸。


第二步：素材配置 (📂 素材分頁)
上傳並管理遊戲圖片。


圖騰管理：

點擊 「🔄 圖騰上傳」 批量選取圖片。

權重 (Weight)：拖動滑桿調整出現機率，數值越高越容易出現。

佔格 (Span)：設定長條符號（如 1x2, 1x3）。

顯示範圍 (Scope)： (v42.0 重點功能)

主盤：勾選後，此圖騰會出現在下方的直向轉輪。

橫轉：勾選後，此圖騰會出現在上方的橫向轉輪。


屬性標記：

WILD：標記為百搭符號，用於對獎邏輯。

SCATTER：標記為觸發符號，集滿 3 個以上進入 FG。

背景/UI：上傳底圖或邊框圖，增強視覺效果。

流程圖片：

觸發過場圖：當 SCATTER 觸發時顯示的圖片（如 "Big Win" 或 "Enter FG"）。

結算報獎圖：FG 結束時顯示的結算畫面。


第三步：動態調校 (⚡ 動態分頁)
調整旋轉的物理手感與節奏。

速度與節奏：

旋轉時間：從按下 SPIN 到第一輪停下的時間。

轉速倍率：全域加速或減速（1.0 為標準）。

停輪間隔 (Interval)：每一輪之間停止的時間差。

(v42.4 優化)：拉長間隔時間不會導致後續轉輪變慢，系統會自動補足圖騰數量以維持恆定速度。

特效細節：


演出模式：

標準轉輪 (Spin)：傳統老虎機滾動。

掉落消除 (Cascade)：符號從上方掉落，支援橫向轉輪同時運作。

單格獨立 (Single)：每一格獨立旋轉。

煞車曲線 (Ease)：設定停輪時的力回饋感（如 BounceBack 觸底反彈、Elastic Q彈效果）。

模糊 (Blur)：設定轉動時的動態模糊程度。


4. 遊戲模式與邏輯 (💾 系統分頁 & 模式切換)
切換模式
在左側面板最上方有 「編輯模式」 切換按鈕：

🏠 Base Game：一般遊戲狀態。

🎰 Free Game (FG)：免費遊戲狀態。

注意：兩個模式的參數（如速度、圖騰權重、背景圖）是獨立儲存的，切換後需分別設定。

觸發機制
進入 FG：在 Base Game 模式下，若盤面（主盤+橫轉）出現 3 個以上 被標記為 SCATTER 的圖騰，旋轉結束後會跳出過場視窗，點擊 START 自動切換至 FG 模式。

FG 流程：FG 模式下，左側會顯示「剩餘局數」。當局數歸零，會跳出結算視窗，並自動切回 Base Game。

對獎系統
系統採用 Way Game (路數) 規則進行簡易對獎。

旋轉停止後，若有連續 3 輪以上出現相同符號（或 WILD），該符號會播放放大與發光特效。


5. 存檔與輸出
在 「💾 系統」 分頁中：

暫存設定：將當前設定存入瀏覽器快取 (LocalStorage)，重整頁面不遺失。

📦 完整專案打包 (推薦)：

將所有設定參數、包含所有圖片資源，打包成一個 .json 檔案下載。

日後點擊 「📂 載入完整專案」 即可完美還原所有內容。

匯出 Config：(開發者用) 匯出給 Cocos 或 Unity 引擎使用的參數檔。


6. 常見操作技巧 (Tips)
滑鼠滾輪：可用於縮放中央舞台的視圖大小。

空白鍵 (Space)：尚未支援，請點擊螢幕下方的 SPIN 按鈕啟動。

除錯：如果轉輪位置跑掉，請點擊頂部工具列的 「回正」 按鈕。

橫向轉輪銜接：v42.2 版本後，橫向轉輪具備「視覺記憶」功能，靜止時看到的符號會在下一次旋轉時自然滑出，不會突兀跳變。
