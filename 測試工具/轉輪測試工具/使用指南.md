# 轉輪測試工具｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

使用圖騰圖片或 Spine 素材，編排 Base Game／Free Game 的轉輪布局、停輪節奏、掉落與流程示意。

## 環境與啟動

執行 `啟動本地伺服器.bat`，需要 Python 3 或 Node.js。保持伺服器視窗開啟，使用它顯示的本機網址；不要自行假設固定埠。

## 操作步驟

1. 在「素材」選定 Base Game／Free Game，再上傳圖騰與介面圖；上傳 Spine 時一併提供骨架、atlas 及所有 PNG。
2. 在「佈局」設定盤面、格子尺寸、可視範圍及遮罩；兩種遊戲模式分別檢查。
3. 在「動態」調整速度、停輪、反彈與掉落模式，按 SPIN 預覽。需固定測試資料時載入模擬輪帶 JSON。
4. 在「系統」用「完整專案打包」保存，或匯出 Cocos／Unity Config 給程式接入。

## 輸出與保存

完整專案為 schema 3 JSON，保存圖片與 Spine 骨架／atlas／貼圖。另有引擎參數輸出及錄製功能；Config 不是可直接運行的完整遊戲。

## 常見問題與限制

- LocalStorage 暫存只在目前瀏覽器環境，不是備份；交付請用完整專案。
- 舊 schema 2 未保存的 Spine 資源需重新綁定；骨架版本須與內附播放器相容。
- Spine 不顯示時核對全部 atlas 頁面、檔名與副檔名，並確認使用本機伺服器。
- 研發測試版、舊版本與加可讀模擬資料版是歷史／分支檔案；一般使用以本層入口為準。

## 驗收檢查

重新載入完整專案後，檢查 MG／FG、圖片、Spine、盤面與節奏；關閉再開伺服器也應能正常載入保存檔。
