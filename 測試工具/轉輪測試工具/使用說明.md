# 轉輪測試工具

版本 1.0.1（2026-09-05）

執行「啟動本地伺服器.bat」，需 Python 3 或 Node.js。伺服器僅監聽 127.0.0.1，使用空閒埠；Node 備援會列出網址。輸入圖騰 PNG 與 Spine JSON/SKEL、atlas、全部 PNG；輸出 schema 3 專案 JSON 及引擎參數。舊 schema 2 可讀取，但舊存檔未保存的 Spine 資源需重新綁定。範例頁面使用內附 Spine Player，並非所有 Spine 版本均相容。

本版改善：專案格式升級 schema 3，完整保存 Spine 骨架/atlas/多頁貼圖；本地伺服器改自選埠且不再安装全域套件。
