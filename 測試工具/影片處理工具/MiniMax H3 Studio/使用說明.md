版本 1.0.1（2026-09-05）

首次執行「啟動 MiniMax H3 Studio.cmd」需要 Git for Windows 與網路，安裝到 %LOCALAPPDATA%/MiniMaxH3Studio/movieeasymake。日後直接啟動已安裝版本，不先進行網路更新。需要更新時執行「檢查更新 MiniMax H3 Studio.cmd」；每個 Git 指令預設最多 120 秒，失敗保留已安裝版。installed-version.json 記錄實際 commit。模型、API 與影片生成功能由 H3 主程式負責，本工具包只分發啟動器。
