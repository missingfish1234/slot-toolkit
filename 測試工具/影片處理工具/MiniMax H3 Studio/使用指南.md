# MiniMax H3 Studio 啟動器｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

安裝並啟動外部 H3 Studio 主程式。此資料夾只提供啟動／更新入口，不包含模型、個人 API 金鑰或完整影片生成系統。

## 環境與啟動

Windows；首次需 Git for Windows 與網路。執行 `啟動 MiniMax H3 Studio.cmd`；Python 與引擎需求依被安裝主程式的提示處理。

## 操作步驟

1. 首次啟動，等候主程式安裝到 `%LOCALAPPDATA%\MiniMaxH3Studio\movieeasymake`。
2. 依 H3 Studio 畫面設定本機／遠端引擎與自己的連線資料，不要使用其他人的金鑰。
3. 之後直接使用啟動 CMD；要更新才執行 `檢查更新 MiniMax H3 Studio.cmd`。更新完成再啟動。

## 輸出與保存

啟動器建立本機程式安裝與 `installed-version.json` 版本紀錄。影片、模型與任務的保存方式由 H3 主程式負責，不在此工具包中同步。

## 常見問題與限制

- 每個 Git 指令預設最多 120 秒；網路／Git 失敗時保留已安裝版本，不要直接刪除安裝目錄。
- 啟動器安裝成功不表示模型／GPU／遠端 API 已可用；生成失敗需看主程式訊息。
- 移除工具包啟動器不等於移除 H3 本機資料；清理前先備份模型、設定與成果。

## 驗收檢查

第一次確認能開啟主畫面；第二次確認直接啟動。查看版本紀錄區分啟動器版本與 H3 主程式 commit。
