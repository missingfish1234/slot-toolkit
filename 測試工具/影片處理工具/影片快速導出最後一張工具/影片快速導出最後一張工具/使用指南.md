# 影片快速導出最後一張工具｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

將單支或整個資料夾影片的最後可讀畫面輸出成 PNG／JPG，適合整理尾幀參考圖。

## 環境與啟動

Windows + Python 3。首次執行 `fix_package.bat` 建立專用 `.venv` 並安裝依賴；日後用 `run_tool.bat` 開啟，不要只搬走主 Python 檔。

## 操作步驟

1. 選「單一影片」或「批次資料夾」，並指定輸出位置。
2. 選 PNG／JPG，再按對應的「輸出單一影片最後畫面」或「批次輸出資料夾影片」。
3. 觀察處理結果；需要停止時按「取消」，等待目前解碼呼叫返回。

## 輸出與保存

輸出 PNG／JPG；沒指定位置時使用影片同層或資料夾內的 `last_frames`。同名會加 `_2`、`_3`，不覆寫既有圖；取消不刪除已完成成果。

## 常見問題與限制

- 可選 MP4／MOV／AVI／MKV／WebM／M4V，但能否讀取依 OpenCV 解碼器及實際編碼。
- 無法啟動時先執行 fix_package，查看缺少 Python／套件訊息。
- 最後一格黑畫面可能就是原影片尾幀，請先播放原影片核對。

## 驗收檢查

先用一支已知結尾的影片確認輸出內容，再批次處理；核對成功／失敗數與輸出圖。
