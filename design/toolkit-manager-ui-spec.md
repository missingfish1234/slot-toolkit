# 工具包管理器 UI 設計規格

## 目標

建立一個 Windows 桌面工具包管理器，讓同事可以從 GitHub 公開倉庫檢視、下載、更新、開啟工具；管理者可以掃描本機工具資料夾並產生工具索引。

## 視覺方向

- 風格：Windows 11 風格的內部管理工具，清楚、乾淨、偏工作台介面。
- 主色：白色背景、深灰文字、藍色主操作、綠色最新版、橘色可更新。
- 圓角：主要卡片與按鈕 6-8px。
- 陰影：低強度陰影，只用於工具卡片與右側詳情區分層。
- 字體：Windows 預設 UI 字體，繁體中文介面。

## 主畫面版面

### 1. 頂部列

內容：

- App icon
- 標題：工具包管理器
- GitHub 同步狀態
- 最近同步時間
- 主要操作：
  - 重新整理
  - 檢查更新
  - 管理者模式
- Windows 視窗控制鈕

狀態文字範例：

- 已同步（2 分鐘前）
- 正在同步...
- GitHub 連線失敗
- 索引檔讀取失敗

### 2. 左側分類欄

寬度建議：260-280px。

第一組：

- 全部工具
- Sharder
- SPINE相關工具
- 數字圖片工具
- 測試工具

第二組：

- 已安裝
- 可更新

底部：

- 設定

每個分類右側顯示數量徽章。

### 3. 主內容區

上方：

- 搜尋框：搜尋工具、用途或標籤
- 篩選按鈕
- 排序選單

清單區：

- 建議使用雙欄工具卡片。
- 視窗較窄時改成單欄。
- 每張卡片固定高度，避免下載狀態改變時跳動。

工具卡片內容：

- 工具 icon
- 工具名稱
- 分類
- 用途描述，最多兩行
- 本機版本
- 雲端版本
- 更新日期
- 狀態標籤
- 操作按鈕

操作按鈕依狀態顯示：

- 未安裝：下載、資料夾禁用、更多
- 已是最新版：開啟、資料夾、更多
- 可更新：更新、資料夾、更多
- 下載中：進度、取消
- 更新中：進度、取消
- 錯誤：重試、詳情

### 4. 右側詳情欄

寬度建議：400-440px。

內容：

- 工具 icon
- 工具名稱
- 分類
- 描述
- 主要操作按鈕
- 本機版本
- 雲端版本
- 更新時間
- 安裝位置
- 工具大小
- GitHub 來源
- 專案頁面
- 標籤
- 版本歷史
- 更新日誌

沒有選取工具時顯示：

- 提示選擇一個工具查看詳情
- 最近更新工具列表

## 狀態設計

| 狀態 | 顏色 | 主按鈕 | 說明 |
| --- | --- | --- | --- |
| 未安裝 | 灰色 | 下載 | 本機尚未下載 |
| 已是最新版 | 綠色 | 開啟 | 本機版本等於雲端版本 |
| 可更新 | 橘色 | 更新 | 雲端版本較新 |
| 下載中 | 藍色 | 取消 | 顯示下載進度 |
| 更新中 | 藍色 | 取消 | 顯示更新進度 |
| 錯誤 | 紅色 | 重試 | 下載或解壓失敗 |

## 管理者模式

入口：頂部列「管理者模式」。

管理者模式畫面包含：

- 掃描本機工具資料夾
- 顯示新工具
- 顯示缺少描述檔的工具
- 編輯工具名稱、分類、描述、版本、入口檔
- 產生或更新 tools-index.json
- 檢查 GitHub repo 結構
- 開啟 GitHub 倉庫

第一版先做本機掃描與索引產生，不直接做 git commit/push。

## 設定頁

設定項目：

- GitHub Repo URL
- 工具安裝位置
- 自動檢查更新間隔
- 啟動時自動檢查更新
- 下載完成後是否自動開啟資料夾
- 管理者工具根目錄

## 建議資料欄位

```json
{
  "id": "sharder",
  "name": "Sharder",
  "category": "Sharder",
  "description": "高效能資源打包與解包工具，支援多種遊戲引擎格式。",
  "version": "1.4.2",
  "path": "tools/Sharder",
  "entry": "Sharder.exe",
  "icon": "tools/Sharder/icon.png",
  "tags": ["打包", "解包", "資源", "Sharder"],
  "updatedAt": "2026-06-11",
  "size": "28.7 MB",
  "changelog": [
    "修正大量小檔案處理時的記憶體使用問題",
    "新增自訂壓縮策略設定",
    "改善解包速度"
  ]
}
```

## 第一版功能範圍

- 讀取 GitHub 上的 tools-index.json
- 顯示工具列表
- 分類瀏覽
- 搜尋
- 狀態比對：未安裝、已是最新版、可更新
- 下載工具
- 更新工具
- 開啟工具
- 開啟工具資料夾
- 管理者掃描本機工具並產生 tools-index.json
