# Cocos Creator 3.8 滾分 QA 插件｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

直接改變 Scene 中的 cc.Label 字串，測試 BMFont 滾分、字距及實際字級是否縮小。需要含 Label 的測試節點與要比較的字型。

## 環境與啟動

Cocos Creator 3.8.x。解壓 `rolling-score-tester-v1.2.1.zip`，將 `rolling-score-tester` 放進 `<專案>/extensions/`；重新整理／啟用擴充功能，開啟「面板 → 滾分 QA 測試工具」。

## 操作步驟

1. 先保存 Scene，再選取 Label 節點，按「綁定目前選取」；有多個 Label 時核對下拉選單的節點及字型。
2. 設定起始／結束分數、秒數、格式與 Easing，按「開始滾分」。建議面板停駐主視窗。
3. 執行「字距／縮放壓力測試」，比對設定字級、實際字級及同格式寬度。
4. 停止後確認還原原字串，需要回報時按「複製 JSON 報告」。換字型請重新確認目標。

## 輸出與保存

輸出到剪貼簿的 JSON 報告與面板監測資料；不是產生新 FNT。預覽會改 Scene 字串，停止／關閉後須確認還原，再決定是否儲存 Scene。

## 常見問題與限制

- actualFontSize 小於 fontSize 才是實際 SHRINK；只有外框寬度不同，不足以判定整排縮放。
- Scene 寫入上限為 15 FPS；面板是診斷工具，不是 60 FPS 正式播放效能測試。
- 畫面不動時先核對所綁定 Label、字型、是否被其他腳本持續改寫，以及插件是否仍是舊版。
- 相同位數仍要區分千分位／小數／後綴格式；長字串超出框寬可能是預期的 SHRINK。

## 驗收檢查

同一字型測試 11111、99999、41414、千分位與最長字串，將報告和 Label Overflow／框寬／Scale 一起記錄。
