# Spine Turn Studio v1.11｜圖片翻轉製作器

Git／工具包下載提供原始碼，請從 [使用指南](使用指南.md) 開始，並先安裝 Python 3.12。下文的免安裝 ZIP 說明適用另外打包的版本，Git 倉庫不包含 EXE、執行環境或私人測試輸出。

用單張透明圖片製作 **Spine 3.8／4.0／4.2 可編輯的鑽石、石塊、硬幣與不規則厚片翻轉動畫**。v1.10 新增「不規則透明輪廓」，沿圖片的凹口、凸瓣與真正透明的孔建立厚度側壁。支援正反面掃光、鑽石切線對齊、圈選凸起、Y／Z 彈跳、明暗及透明 PNG 序列。可將原圖和設定儲存成可重新開啟的 `.spturn` 編輯檔。所有圖片均在本機處理。

## 開始使用

若使用完整原始碼資料夾，雙擊 `啟動圖片翻轉工具.bat` 會以此資料夾的 `main.py` 啟動。執行環境位於 `.build/venv`，第一次使用會準備所需套件；也可手動執行 `準備執行環境.bat`。啟動失敗會停止並留下 `.build/launch.log`，不會改用其他位置的舊程式。

解壓縮 `SpineTurnStudio-1.11.0-win64.zip` 後，開啟 `SpineTurnStudio` 資料夾並雙擊 `SpineTurnStudio.exe`。若使用原始碼專案，v1.11 免安裝版位於 `dist/v1.11/SpineTurnStudio/`。請保留整個資料夾；只複製 EXE 會缺少必要檔案。此版本已包含 Python、Pillow、NumPy、Tk 與圖片拖放元件。

v1.11 重新整理工作區：素材改為上方三張卡，可分別替換、清除及互換正反面；厚度、時間、輸出大小和旋轉方向固定在右上方。右側設定依目前模式顯示，凸起與斜面可展開；匯出固定在底部。收合素材、拖曳右側分隔線，或按 F8「專注預覽」可放大檢查畫面。舊編輯檔和既有動畫設定可繼續使用。

v1.10.2 修正不規則外型正反面放同圖時，背面與厚度側壁不對齊、出現翹出邊緣的問題。同圖會自動視為單張圖的實體翻轉，背面依旋轉軸鏡像，文字也會鏡像；圖片原檔保持完整。已有編輯檔重新開啟後即可套用，Spine 檔案需重新匯出。

v1.10.1 納入最新的預覽快取與不規則物件繪製調整，預覽改由背景運算更新，減少介面等待。複雜輪廓仍會影響播放流暢度，實際速度依圖片、設定與電腦而異。匯出區及完成提示會標示應使用的 Spine 版本；一般新專案預設為 Spine 4.0，開啟舊編輯檔時保留原設定。

1. 將圖片拖到上方正面、背面、側邊卡片，或按「替換」選圖。每張素材可單獨清除；「互換」會交換已提供的正反面。素材收合時，按「顯示素材」展開。
2. 在右側選擇「一般物件」或「鑽石」。厚度、一圈時間、輸出大小與旋轉方向在上方固定顯示；一般物件到「外形」選擇外框，鑽石到同名分頁編輯切面。不同模式會隱藏不適用的設定。
3. 視需要在「彈跳」、「Z 軸」與「光效」調整獨立 Y／Z 彈跳、掃光及明暗；各彈跳頁都能開啟時間設定。設定較多時捲動右側內容，滾輪不會誤改欄位的數值。
4. 在預覽上方選擇動畫、背景與畫面縮放。下方提供起終點、前後逐格、時間軸，以及實際角度輸入；輸入角度後按 Enter 或「套用」。按 F8 可切換專注預覽。
5. 在底部選擇 Spine 3.8、4.0 或 4.2，再按「匯出 Spine 專案…」。程式會建立獨立專案子資料夾；同名時自動加上編號，保留先前輸出。
6. 若已勾選「同時建立原生 .spine」，完成後直接以 Spine 開啟輸出的 `.spine`。

只要單張圖製作石塊時，放入正面透明 PNG，清空背面及側邊欄位，再勾選「石塊模式（前後斜面相接）」即可。背面會沿用正面，側邊貼圖不參與此模式。

程式啟動時會載入一組範例硬幣，可先確認操作流程。

底部匯出區固定顯示，不會隨分頁捲動。範例集中在右上角「範例」選單。套件另附 `examples/irregular-v1.10/irregular.spturn`，可用工具重新開啟並繼續調整；同目錄的 `spine-3.8`、`spine-4.0`、`spine-4.2` 分別提供相符版本的原生專案，並附匹配的 PNG 序列與 GIF。

點一下預覽畫面後，可用 Space 播放／暫停、左右方向鍵逐格、Home／End 到起終點。輸入欄位和對話框會保留原本的按鍵功能；F8 在主視窗可隨時切換工作區。預覽上的滾輪可縮放畫面，「適合」恢復 100%；這些檢視操作不會改變匯出大小。半圈動畫的角度範圍分別是 0–180° 和 180–360°。

## 原始碼專案的啟動與打包

以下入口一律以批次檔所在的專案資料夾為準，不會轉用其他位置的舊來源或舊 EXE。

| 入口 | 用途 | 產出位置 |
| --- | --- | --- |
| `啟動圖片翻轉工具.bat` | 啟動目前的原始碼 | 使用本地 `.build/venv` |
| `重新打包EXE_測試版.bat` | 測試成功後產生獨立測試版 | `dist/dev/時間戳/SpineTurnStudio/` |
| `重新打包EXE_正式版.bat` | 依目前版號及本地驗證產生正式版 | `dist/v版號/SpineTurnStudio/` 與專案根目錄的 ZIP |

環境設定與日誌都放在 `.build/`；需要重新準備環境時執行 `準備執行環境.bat`。`檢查啟動與打包設定.bat` 只列出設定，不會啟動程式或打包。測試或啟動失敗就停止，沒有跳過失敗或回退舊版本的選項。

正式打包要求 `main.py` 的版號與成品版號一致，且單元、Spine 原生與公開範例驗證均合格。已有同版成品或仍指向歷史工作位置的驗證資料時會停止；要產生新的正式版，須先完成新版與當次本地驗證。原有成品和歷史報告保留供追溯。

Git 內附自製示範圖與 `examples/irregular-v1.10` 公開範例。私人素材、歷史 QA、建置環境、輸出和舊版交付包不納入版本控制；少數需要本地歷史基準的測試會在缺少資料時明確跳過，其餘自含測試仍會執行。這些跳過不代表已完成 Spine 原生驗證，正式發行仍須產生當次本地證據。

## 儲存並繼續編輯

按上方「儲存編輯檔」保存 `.spturn`；下次按「開啟編輯檔」即可繼續製作。可使用 Ctrl+S 儲存、Ctrl+O 開啟；另存新檔使用 Ctrl+Shift+S。

`.spturn` 內含原始正面、背面、側邊圖片（僅嵌入實際提供的素材），以及物件模式、不規則輪廓與擷取參數、硬幣掃光參數、鑽石輪廓、獨立前後深度、切面排列與光效、反光分區及各區朝向、圈選頂點、石塊模式、厚度、Y／Z 時間與幅度、明暗、目標 Spine 版本、動畫選擇與預覽設定。可將單一編輯檔搬到其他資料夾或電腦，不需要維持原圖原本的路徑。舊編輯檔會保留原本的形狀，硬幣掃光預設關閉；未提供的背面與側邊仍保留為未提供，開啟時依目前設定處理。

| 檔案 | 用途 |
| --- | --- |
| `.spturn` | 用本工具重新開啟，調整原圖、圈選與製作參數 |
| `.spine` | 用對應版本的 Spine 編輯器調整骨架、網格與動畫 |
| `.json`、`.atlas`、圖集 PNG | 匯入資料或遊戲播放資料，需搭配相符版本 |
| 透明 PNG 序列 | 固定畫布的影格圖片 |

「Y 彈跳」與「Z 彈跳」可分別開關。只要關閉 Y 彈跳、啟用 Z 彈跳，即可製作只有靠近／遠離鏡頭的動作。

## 準備圖片

| 欄位 | 用途 | 建議素材 |
| --- | --- | --- |
| 正面圖片 | 必填，決定物件長寬 | 真正帶有透明背景的 PNG，物件置中 |
| 背面圖片 | 選填，180 度時的背面 | 以正視背面的方向放入，尺寸比例與正面一致 |
| 厚度／側邊貼圖 | 選填，包覆厚度表面 | 橫向或直向展開的連續側邊材質條紋 |

只有一張正面圖片也能製作：空白背面會沿用正面，空白側邊會使用預設金色條紋材質。這些替代素材會記錄在 `manifest.json`，方便後續換圖。

**厚度貼圖是側邊材質，不是灰階深度圖。** 側邊方向可選自動、橫向或直向。橫向素材的左至右對應外框一圈；直向素材會先轉成橫向，再包覆外框。材質條紋的另一個方向對應正面到背面的厚度；實際厚度由「厚度（像素）」設定。卡片可使用紙張邊緣、金屬片或純色材質。

「自動」依長寬判斷：高度大於寬度時使用直向，其餘使用橫向；需要時可手動指定。直向素材會逆時針旋轉 90 度，原本的上到下對應包覆後的左到右。輸出的 `images/edge.png` 已整理成橫向，不需要在 Spine 再旋轉一次。

正反面圖片最好具有相同輪廓與中心。程式會裁去全透明留白，並依正面比例安排背面。棋盤格若已畫進圖片本身，不會自動變成透明；不透明背景也不會自動去背。

## 硬幣旋轉掃光

在「光效」分頁按「試用硬幣掃光」可直接載入範例；使用自己的圖片時，勾選「啟用正反面掃光」，調整「掃光強度」、「光帶寬度」及「光帶傾斜角度」，再按「掃光時間…」設定開始、結束秒數與 1–4 次掃光。時間依目前選取的動畫顯示；切換整圈或半圈時，掃光會維持相同的動畫比例。

掃光貼合正反面，隨翻轉移動；只覆蓋平坦表面，不延伸到厚度側壁或斜面。適用橢圓、矩形、凸多邊形、不規則輪廓、斜面與石塊模式。透明邊緣及孔洞會保留，原圖不被改寫。強度為 0 或關閉時不產生額外光效網格。

光效使用工具產生的白色透明材質、一般透明混合及顏色動畫，不需要額外 shader。輸出的 `.spine` 可繼續編輯掃光網格與透明度；`.spturn` 會保存完整設定。掃光以固定小區塊依序亮起，因此極窄或很強的光帶可能看得出區塊間的亮度差，可增加光帶寬度或降低強度。

先前 v1.9 的 `examples/coin-shine-v1.9/coin.spturn` 仍保留於該版套件，採用原創硬幣圖，在整圈開始的 0–0.5 秒掃過一次。

## 不規則透明輪廓

花瓣、齒輪、凹口徽章等外型，在「外形」分頁選「不規則透明輪廓」，或從右上角「範例」載入不規則範例。外框以正面 PNG 的透明範圍為基準，建立具有厚度的平面物件；透明孔會建立內壁，分離的小島也會保留。

只放一張正面，或正反面放相同圖片時，本模式以正面鏡像作為示意背面，讓不對稱凹口和實體側壁相接；轉到背面時文字也會鏡像。正反面即使檔名不同，只要解碼後的圖片像素相同，也會自動套用。需要不同背面圖案或正讀文字時，請另放入中心與鏡像後實體輪廓相符的背面圖；不對稱的「10」無法同時維持同一個立體外型及兩面都正讀。側邊材質仍可單獨提供。其他模式的背面沿用方式保持原有設定。

- **Alpha 門檻**：決定哪些像素作為實體邊界，預設 16。提高可排除淡光與半透明毛邊；原始貼圖仍保留。
- **輪廓誤差（像素）**：控制簡化程度。數值較小會保留更多細節，也會增加網格與動畫資料量。
- **厚度、旋轉、Y／Z、掃光**：與一般硬幣分開設定的操作方式相同，可輸出 `.spine`、`.spturn` 及透明 PNG 序列。

孔必須是真的透明像素；圖片中塗成綠色、黑色或其他顏色的區域不會自動挖空。不規則模式目前使用一致厚度，斜面、石塊模式與圈選凸起需切回凸多邊形使用。它依平面輪廓建立厚片，不會由單張圖推算不同零件的真實深度或看不見的背面。

輪廓細節多時，即時預覽可能較慢；輸出時仍會依指定影格完整計算。提高輪廓誤差可減少細節與運算量。Spine／遊戲端的播放效能需在實際環境確認。

## 鑽石模式

在「製作模式」選擇「鑽石」，放入一張正面透明 PNG，再到「鑽石」分頁按「調整鑽石輪廓…」。編輯器固定在 0° 正面，直接顯示正式模型的實際切線。頂台、冠部、腰圍與亭部會形成相連的封閉體積，側轉到 90 度時仍保有立體厚度。

1. 先依原圖選「正面為切面」或「正面為稜線」，讓前方是平邊或尖角；再調整俯視角度。
2. 拖「頂台前緣／後緣」對準台面。上下拖動其中一側時，另一側保持原位，台面中心高度與前後深度一起更新。
3. 拖「腰環前緣／後緣」對準冠部與腰帶相接的上緣；腰帶下緣也會顯示，方便辨識厚度。
4. 拖左右寬度、中心或底尖節點，核對完整輪廓。寬度與中心節點調整左右，前後緣與底尖調整上下。
5. 按「套用輪廓與深度」後，主預覽停在正面並暫停，可先比較原圖，再按播放檢查旋轉。取消會還原開啟前的動畫與播放位置。

實線是正面切邊；需要背面結構時勾選「顯示背面線」，以虛線顯示。可疊上原有反光分區作對照。滾輪縮放圖片、中鍵平移，右側設定可捲動；支援復原、重做及恢復開啟時的設定。俯視角度低於 2° 時前後緣幾乎重疊，拖動前後緣前需先提高角度；開啟舊檔不會自動更改角度。

台面與腰部有各自的前後深度，以圖片寬度百分比表示；0 代表沿用自動深度。進階設定中的「中心高度」是整圈中心，前後緣的位置會隨深度及俯視角度改變。台面深度需小於腰部，過度扭曲的比例會顯示提示並保留上一個有效形狀。Z 軸分頁的厚度倍率仍可統一縮放整體深度，一般模式的「厚度（像素）」用於圖形擠出。

切面明暗依各面的方向變化。「掃光」與「星芒」可分別開關及調整強度，會一併輸出到 Spine 與透明 PNG。掃光以貼合切面的小區塊依序亮起；光效使用工具產生的白色材質與一般透明混合，可在 Spine 中繼續編輯網格及顏色動畫。

鑽石模式使用同一張圖片映射各個切面；缺少背面時沿用正面，不需要側邊貼圖。外形以共用中心、等分環形的切面近似，適合頂台、寬腰與底尖清楚的寶石。原圖不對稱的轉角仍可能有些差異，側面材質也會延展或重用。圖片內原有的彩繪與反光會保留；原圖已畫好強烈光影時，可降低「切面明暗強度」，避免疊加後過暗。此模式不會還原鑽石內部折射。

`assets/demo-diamond-aligned.png` 是依模型投影繪製的原創幾何範例。「載入鑽石範例」使用正面切面排列與 24° 俯視角，保留圖片原始畫布，讓實際線框與圖中邊界對應。

## 在原圖上畫鑽石反光分區

先用「調整鑽石輪廓…」設定整體外形，再按「畫切面與反光方向…」。在「畫線模式」選擇「上方四點」或「下方三點」，再按「＋ 新增切面」；沿原圖邊界點滿 4 點或 3 點後會自動封閉，方便上部使用四邊形、下部使用三角形。

需要其他形狀時選「自由畫線」，可畫 3～12 點，點回第一點或按 Enter 封閉。凹角或重疊時會保留草稿，可拖動頂點後按 Enter 重試，或按「取消繪製」。選取已畫好的區域後，調整左右與上下反光方向；各方向支援 −60°～60°，讓不同區域在旋轉時分別變亮或變暗。

最多可設定 24 個封閉凸多邊形，區域不能重疊，相鄰區域可共用邊線。游標接近既有頂點時會吸附；拖動共用頂點時，相鄰切面一起更新。按「套用切面」更新預覽，取消時保留原設定；`.spturn` 會保存全部範圍和朝向。

這些分區控制材質反光與明暗，整體立體外形由鑽石輪廓設定；畫出的任意分區不會自動變成獨立的立體頂點。

## 翻轉分頁

- **物件外形**：圓形／橢圓使用環形側邊，矩形使用四邊厚度。側邊依選定外形建立，不會辨識任意圖案的立體輪廓。
- **旋轉方向**：Y 軸為左右翻轉，X 軸為上下翻轉。
- **厚度**：以輸出圖片像素為單位。正面寬 512 像素的硬幣，可從 20～40 像素開始調整。
- **一圈時間**：控制 `rotate_loop` 完成一圈的秒數；半圈動畫使用一半時間。
- **側邊分段**：增加分段能讓圓形側邊更細緻，也會增加網格與動畫資料量。一般可先使用 32 段。

「依透明外框／凸多邊形」會從正面圖片的 Alpha 擷取凸外框，保留八角形等圖案的轉角，再沿外框建立厚度；側邊分段增加時仍保留原本角點，不會把八角形變成圓形。正面必須具有真正透明的背景。這個舊選項仍使用凸外框近似；需要保留凹陷或洞口內壁時，請選「不規則透明輪廓」。

未手動畫線時，「自動斜面寬度」大於 0 會建立「中央面、斜面環、側壁」的不同深度層次，適合八角寶石與有倒角的徽章。自動寬度以圖片短邊的百分比計算，凸起高度以物件厚度的百分比計算。例如寬度 7%、高度 25% 可先觀察斜轉時的立體層次；自動寬度設為 0 且未手動畫線時，使用平面外框擠出的效果。

斜面沿用原圖對應位置的貼圖，不會重畫圖案。正視時保留原圖的整體外觀，轉向時才顯示中央面、斜面與側壁的深度差。它仍是供 Spine 編輯的網格與變形動畫。

斜面最外緣最多向內取樣 1 個來源像素，避免原圖的半透明邊緣在側壁接縫透出；狹窄區域會自動縮小取樣距離。中央面的貼圖對應與來源圖片維持原樣。

[參考影片〈Spine 2D Tutorial Stone 3D Rotation〉](https://www.youtube.com/watch?v=EOh6Mk9Ohng&t=83s)展示中央面、斜面及側壁的深度層次。本工具以網格、Deform 與骨骼縮放呈現這個分層概念，保留正反面原圖各區域的貼圖對應。

## 單圖石塊模式

「石塊模式（前後斜面相接）」以前後斜面直接接成一條封閉稜線，中間沒有側邊帶。正反面圖片包覆斜面，因此無須提供額外側邊貼圖，改動側邊材質也不會影響石塊；原圖本身的顏色與裝飾保持原樣。

此模式使用凸多邊形外框，勾選時會切換至對應外形。可使用自動內縮，或按「畫凸起範圍…」手動圈選。沒有手動範圍且自動寬度為 0 時，會採短邊 7% 的預設內縮。

整體厚度保持原設定：正反面各位於中央稜線兩側的半個厚度位置。例如厚度 32 像素，正面與背面各距中央 16 像素。凸起高度固定為厚度的 50%，高度控制在此模式鎖定；原先的高度數值會保留，關閉石塊模式後可繼續調整。關閉石塊模式即可使用原本具有側邊帶的硬幣／徽章造型。

## 在圖片上畫凸起範圍

1. 放入透明正面圖，在「翻轉」分頁按「畫凸起範圍…」。
2. 按「清除重畫」，沿希望抬高的區域依序點選頂點，再按「完成輪廓」。琥珀色是凸起的平整面，與青色外框之間會形成斜邊。
3. 拖曳頂點調整位置；點選邊後可「選取邊加點」，也可刪除頂點。提供「復原」與「重做」；滾輪縮放、空白鍵拖曳平移，「適合畫面」重設檢視。
4. 在一般側邊帶模式可設定「凸起高度（占厚度%）」；石塊模式顯示固定 50%。按「套用凸起範圍」返回預覽，取消會保留原設定。

目前支援**一個封閉凸多邊形、3～32 點、單一高度**。範圍須完全位於透明外框內，離外框至少 1 個來源像素，不能交叉、凹入或重疊。無效範圍會顯示原因並停用套用，可調整頂點或復原。

手動範圍可偏離中心，內外框頂點數也可不同，例如外八角形、內五邊形。套用後會優先使用手動範圍，自動寬度暫停使用，寬度為 0 也能建立凸起。一般側邊帶模式的高度為 0 時回到同一平面；石塊模式的高度固定。主畫面的「恢復自動範圍」會清除手動畫線，重新依自動寬度建立內框。

正反面使用同一個實體凸起輪廓及高度，背面以貼圖方向調整保持可讀；目前不提供兩面各自圈選、多個區塊或逐像素高度圖。來源正面換成另一張圖片時會清除手動範圍；更換背面或側邊圖不會清除。頂點與高度保存在匯出的 `manifest.json`，並反映於 `.spine` 網格和 PNG 序列。

## 彈跳分頁

| 控制項 | 預覽 | 匯出到 Spine |
| --- | --- | --- |
| 預覽縮放 | 放大或縮小檢視畫面 | 不改變輸出大小或動畫資料 |
| 基礎縮放（%） | 改變物件的實際大小 | 保存為可編輯骨骼縮放 |
| Y 軸彈跳啟用與高度 | 旋轉時加入上下彈跳 | 保存為可編輯骨骼位移關鍵格 |
| 空中放大（相對基礎，%） | 改變彈跳高點的大小 | 保存為可編輯骨骼縮放關鍵格 |
| 落地壓縮 | 控制落地時的壓扁程度 | 保存為可編輯骨骼縮放關鍵格 |

預覽縮放適合檢查細節；需要讓遊戲中的物件更大或更小時，請調整輸出縮放。動作設定會跟隨選定動畫一起預覽與匯出，無須在 Spine 重新建立彈跳或縮放。

基礎縮放 100% 保留圖片大小，50% 為一半大小；空中放大是相對於基礎大小的百分比，例如 115% 表示高點再放大 15%。彈跳高度獨立控制位移幅度，落地壓縮用來調整接觸地面時的寬扁變化。

啟用彈跳後，每個動畫各包含一次完整的「預備、起跳、高點、落地、壓縮、恢復」。因此半圈動畫的彈跳也會在半圈時間內完成。程式會補償縮放造成的中心位移，讓落地接觸位置保持穩定。

## 自訂彈跳時間

先在中央選擇動畫，再按「彈跳時間…」。視窗以該動畫的**秒數**顯示 Y 與 Z 時間，兩組可各自安排：

| 動作 | 可調整的時間點 |
| --- | --- |
| Y 上下彈跳 | 起跳、到達高點、落地、落地後恢復完成 |
| Z 靠近／遠離 | 開始靠近／遠離、到達深度高點、返回原位 |

「起跳」指離地時刻，之前會有短暫預備壓縮；落地後仍會繼續執行原本的翻轉，彈跳不需要占滿整段動畫。Y 時間須依序為「起跳 < 高點 < 落地 ≤ 恢復完成」，Z 時間須為「開始 < 高點 < 返回原位」，各時間皆須在動畫範圍內。

若「落地」與「恢復完成」設為同一時間，會略過落地後的壓縮回復區間。

時間在專案內以動畫長度的比例保存。例如整圈為 2 秒時，將 Y 設為 0.6／1.0／1.4／1.7 秒，切換成 1 秒的半圈動畫後會相應顯示為 0.3／0.5／0.7／0.85 秒。修改一圈時間時也會依比例調整；同一組比例套用至三個輸出動畫。Y／Z 是否啟用與幅度仍由各自分頁控制。

## Z 軸分頁

Y 軸與 Z 軸的開關各自獨立。需要只做靠近／遠離時，關閉「啟用 Y 軸彈跳與落地」，再開啟「啟用 Z 軸靠近／遠離彈跳」；此時物件中心不會上下跳動。

| 控制項 | 作用 |
| --- | --- |
| 前後厚度縮放（%） | 100% 保留原厚度；200% 為兩倍厚度，不會直接放大正面圖的長寬 |
| 鏡頭距離（像素） | 控制近大遠小的反應程度 |
| 基礎 Z 位置 | 正值靠近鏡頭、看起來更大；負值遠離鏡頭、看起來更小 |
| Z 軸靠近／遠離彈跳 | 啟用每段動畫中的深度往返 |
| Z 彈跳幅度 | 正值先靠近再返回，負值先遠離再返回 |
| Z 彈跳頂點厚度（相對基礎，%） | 控制深度動作高點的厚度倍率；100% 保持厚度 |

若只需要近大遠小，將頂點厚度設為 100%；若只需要厚度變化，將 Z 彈跳幅度設為 0，再調整頂點厚度。基礎 Z 位置在未啟用 Z 彈跳時仍然有效。

深度採用物件中心到鏡頭的距離，將近大遠小轉成均勻的平面縮放；厚度則透過側邊與正反面網格變形表示。這是適合 Spine 的 **2.5D 近似**，不是原生 3D 座標或逐頂點透視。靠近後的位置最多可達鏡頭距離的 90%，避免投影接近無限大。

## 光效分頁：轉向明暗

可啟用或停用正反面隨旋轉變暗，調整「最暗亮度」、「變化曲線」與「光源角度」。最暗亮度控制暗面保留多少原圖亮度；變化曲線控制亮面與暗面之間的過渡；光源角度控制最亮姿勢的位置。側邊陰影可另行啟用或停用。

變化曲線為 1 時使用一般過渡；數值提高會縮小亮面區間，數值降低會延長亮面區間。最暗亮度為 100% 時保留原圖亮度，不產生變暗效果。

這些光影變化會保存到 Spine 的插槽顏色動畫，可繼續修改。它是在原圖上調整亮度，不會重畫圖案內的陰影、高光或反射；原圖已有的光影仍然保留。

## 選擇 Spine 版本

每個版本使用對應的骨架、動畫與貼圖資料格式；遊戲端請使用相同系列的 Spine runtime。

| 選項 | 預設指定修訂版本（已實際驗證） | 原生專案與資料 |
| --- | --- | --- |
| Spine 3.8 | 3.8.99 | 3.8 格式 |
| Spine 4.0 | 4.0.56 | 保留原有 4.0.56 格式 |
| Spine 4.2 | 4.2.43 | 4.2 格式 |

載入編輯檔時會保留其中的完整修訂版本；上表是一般選擇系列時的預設值。首次產生原生檔可能需要本機 Spine 啟動器備妥指定版本。工具會明確指定該版本；未成功建立時，仍保留可匯入的 JSON 與圖片。

請用匯出時指定的版本開啟專案，例如 4.2.43 的檔案須以 Spine 4.2.43 開啟。將 4.2 JSON 匯入 Spine 4.0 可能遺失翻轉用的網格動畫；需要 4.0 時，請在本工具選擇 4.0 後重新匯出。

Spine 3.8／4.2、鑽石模式或啟用硬幣掃光時，工具可能自動選用 31、32、60 等編輯器時間軸 FPS，以保留關鍵格時間與精度。此設定會記錄於匯出資料，動畫秒數、關鍵格時間與幾何保持不變；PNG 序列仍使用你選擇的輸出 FPS。4.0 一般物件未啟用掃光時沿用原有設定。

## 在 Spine 編輯器中使用

工具會自動尋找本機 Spine；找不到時，可按「選擇 Spine 程式」選取 `Spine.com` 或 `Spine.exe`。建議使用同一安裝資料夾內的 `Spine.com`。

原生 `.spine` 由你本機已啟用、支援網格的 **Spine Professional／Enterprise** 匯入建立，工具沒有附帶 Spine 編輯器。請在 Spine 啟動器選擇並啟動對應的 3.8.99、4.0.56 或 4.2.43，再開啟相符的原生專案。

開啟專案後，在 **Animate／動畫模式**選擇：

| 動畫名稱 | 動作 |
| --- | --- |
| `rotate_loop` | 正面開始，完整旋轉 360 度，可循環播放 |
| `flip_to_back` | 正面翻至背面，180 度 |
| `flip_to_front` | 背面翻回正面，180 度 |

這是以 Spine 網格、Deform 變形與附件顯示切換製作的動畫。可以在 Spine 繼續修改網格、變形關鍵格、動作時間與附件；Y 軸彈跳與縮放保留在 `turn` 骨骼，深度的均勻縮放另存於 `depth` 骨骼，厚度變化保留在網格動畫，`root` 保持固定。骨骼動作使用主要姿勢關鍵格與曲線；鑽石切面保留較密的變形關鍵格。硬幣掃光沿用原有物件變形，以額外的透明度關鍵格控制亮帶。完整翻轉姿勢已建立在動畫時間軸中。

如果未建立原生檔，仍會輸出可匯入的 JSON。在相符版本的 Spine 選擇 **Import Data／匯入資料**，指定該 JSON，之後另存為 `.spine`。JSON 沒有被改副檔名冒充原生專案。

Spine 4.0 的原生 JSON 匯出會對部分數值四捨五入；需要保留更多數值精度時，可從 Spine 匯出 Binary。原生專案驗證使用 Binary 重新匯出後的官方 runtime 結果核對，JSON 的量化差異另行記錄。[Spine 官方精度說明](https://fr.esotericsoftware.com/forum/d/16197-rounded-off-value-in-v4017/8)

## 輸出內容

```text
coin/
  coin.spine        原生專案；本機 Spine 成功匯入時才會出現
  coin.json         選定版本的 Spine 骨架與動畫資料
  coin.atlas        圖集區域資料
  coin.png          圖集圖片
  images/
    front.png       正面圖
    back.png        背面圖
    edge.png        側邊材質
  manifest.json     參數、動畫名稱、尺寸、素材替代與限制紀錄
```

請將專案與 `images` 資料夾一起保存，才能繼續編輯；遊戲端使用對應版本的 JSON、atlas 與圖集 PNG。若在 Spine 中修改專案，請從 Spine 重新匯出遊戲資料，以保持專案與動畫一致。

## 透明 PNG 序列

按「匯出透明 PNG 序列」，選擇動畫、影格率與畫布寬高，再指定輸出位置。序列包含目前的翻轉、Y／Z 彈跳、縮放與明暗設定，輸出為 straight alpha 的 RGBA PNG；棋盤格、背景色與地面參考線不會輸出。

輸出使用一個固定畫布與整段動作共用的取景範圍，將完整動作放入畫面，不會每張重新置中或重新縮放。畫布支援 64～4096 像素，影格率支援 1～120 FPS。預覽縮放只影響工具內的顯示；PNG 的取景依輸出畫布與整段動作範圍自動安排。

- 整圈循環會輸出 `round(秒數 × FPS)` 張，不重複最後的起始姿勢。例如 2 秒、30 FPS 為 60 張。
- 半圈動畫會保留精確結束姿勢。例如 1 秒、30 FPS 為 31 張，包含開始與結束。
- 檔名為 `frame_0000.png`、`frame_0001.png` 等；`sequence.json` 記錄影格數、實際影格率、共用取景與輸出狀態。
- 輸出中可取消；已完成的影格會保留，狀態記錄為取消，不會顯示為完整序列。

PNG 序列以工具共用的圖片繪製器計算，依循同一組匯出動畫網格與骨骼曲線，並非由 Spine 的原生 GPU 渲染器擷取。PNG 序列與可編輯 Spine 專案是兩種獨立輸出，匯出序列不會取代原生專案。

## 適用範圍

一般物件模式模擬具有厚度的平面外形；鑽石模式使用可調剖面建立對稱切面體積。兩者以固定 X 軸或 Y 軸翻轉，並可加上中心距離造成的近大遠小。多邊形模式擷取的是平面凸外框，不會從單張圖重建角色、雕像或任意 3D 模型，也不會補出未提供的背面細節。

一般平面外形預設約每 15 度建立變形關鍵格；斜面與鑽石使用較密的角度，並加入切面可見性切換所需的時間點。鑽石啟用光效時約每 3 度取樣。變形關鍵格之間使用線性插值，因此圓弧投影存在少量近似誤差。外框也由有限分段近似，建議先用實際遊戲顯示大小檢查效果。

一般硬幣與圖示適合使用正面清晰、側邊干淨且原有陰影不過重的素材。可調光影提供角度相關的明暗變化，並不等同於 3D 材質、環境反射或投射陰影。

## 原始碼啟動

此節供需要修改工具的人使用；一般使用者直接開啟免安裝版即可。

安裝 `requirements.txt` 所列依賴後，執行 `python main.py`，或使用 `啟動圖片翻轉工具.bat`。拖放依賴缺少時仍可點選欄位載入圖片。

原生 Spine 匯入方式依據 [Spine 匯入說明](https://esotericsoftware.com/spine-import)與[命令列說明](https://esotericsoftware.com/spine-command-line-interface)。匯入與播放資料應使用相符的 Spine 3.8、4.0 或 4.2 系列。
