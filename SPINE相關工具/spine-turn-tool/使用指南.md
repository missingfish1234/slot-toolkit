# Spine 圖片翻轉製作器｜使用指南

將透明 PNG 製作成可在 Spine 繼續編輯的翻轉動畫，或匯出透明 PNG 序列。適合硬幣、徽章、不規則厚片與近似立體的鑽石。

## 安裝與啟動

在工具包管理器重新整理清單，找到 **SPINE相關工具 → Spine 圖片翻轉製作器**，即可下載或更新至 **1.14.0**。Windows 64 位元免安裝包已包含執行環境，無須另裝 Python。

也可從 [GitHub 發行頁](https://github.com/missingfish1234/slot-toolkit/releases/tag/spine-turn-studio-v1.14.0) 下載 `tool-spine-turn-tool-1.14.0-win64.zip`。請完整解壓縮並執行 `啟動圖片翻轉工具.bat`。

**Git 原始碼：**Git 倉庫本身提供原始碼；使用原始碼時，請先在 Windows 安裝 **Python 3.12**，再依下列步驟啟動。

1. 完整保留原始碼資料夾，雙擊 `啟動圖片翻轉工具.bat`。
2. 首次啟動會建立本工具的 `.build/venv` 並準備套件，請保持網路可用並等候完成。也可先執行 `準備執行環境.bat`。
3. 程式會載入範例硬幣。若啟動失敗，檢查 `.build/setup.log` 或 `.build/launch.log`；入口不會轉用其他資料夾的舊程式。

圖片在本機處理。建立原生 `.spine` 另需已安裝、啟用且支援網格的 Spine Professional／Enterprise；本工具不附 Spine 編輯器。

## 放入圖片與設定外形

1. 將 PNG 拖到上方的「正面、背面、側邊」素材卡，或按「替換」選圖；卡片可清除素材，也能互換正反面。
2. 正面是必要素材，背面可省略。側邊是沿厚度外圈使用的**材質貼圖**，不是深度圖；省略時使用工具產生的側邊材質。
3. 在右側選擇物件模式，調整厚度、一圈時間、輸出大小與旋轉方向。一般物件可到「外形」選擇圓形、矩形、凸多邊形或「不規則透明輪廓」。
4. 不規則模式會依透明範圍保留凹口與真正透明的孔；圖片內已上色的區域不會自動挖孔。

**不規則模式的同圖背面：**未提供背面，或正反面提供相同圖片內容時，背面會依旋轉軸鏡像，文字也會鏡像，使背面與厚度側壁對齊；原圖不會被修改。若提供不同的背面圖，請讓它對應同一實體的反面輪廓。

可先用「開啟」載入 [不規則範例](examples/irregular-v1.10/irregular.spturn)。彈跳、Z 軸、掃光、明暗及鑽石切面等進階設定，見 [完整說明](README_zh-TW.md)。

## 同時在畫面內轉一圈（Z 軸）

1. 保留上方原有的左右／上下翻轉方向，再勾選右側常用設定的「同時平面旋轉一圈（Z 軸）」。
2. 選擇順時針或逆時針；按「時間…」設定開始旋轉與完成 360° 的秒數，預設使用整段動畫。
3. 起訖時間可與 Y／Z 彈跳分開安排。需要平放落地時，可讓平面旋轉在 Y 軸落地之前完成；上下彈跳的路徑仍沿畫面垂直方向。
4. 整圈及兩個半圈動畫各自轉滿一圈；切換動畫或修改總時間時，起訖時間按比例調整。

畫面內旋轉會一起寫入 `.spturn`、Spine 3.8／4.0／4.2 和透明 PNG 序列；Spine 中可編輯新增的 `spin` 骨骼旋轉。關閉此開關保留原本表演，舊編輯檔預設關閉。

可直接開啟 [平面旋轉範例](examples/irregular-v1.10/z-spin.spturn) 試用。下方「角度」仍代表原本的立體翻轉角度，平面旋轉依同一段動畫的進度疊加。

## 多個動畫：各自設定，輸出成同一個 Spine 檔

視窗上方「專案」右邊的「目前動畫」可以建立多個動畫，每個動畫有自己的設定，匯出時全部放進同一個 Spine 專案（PNG 序列也可一次輸出全部）。

- **＋**：新增一個動畫（預設整圈旋轉）。**複製**：複製目前動畫的所有設定。**改名**、**刪除**：改目前動畫的名稱或刪除它（至少保留一個）。
- 動畫名稱就是 Spine 裡的動畫名稱，不可重複，也不可包含 `< > : " / \ | ? *`。
- 切換「目前動畫」時，右側設定和預覽會換成那個動畫的內容；改動只影響目前動畫。

**每個動畫各自設定**：動作（預覽左上的「動作」選單）、一圈秒數、輸出大小、翻轉軸（左右 Y／上下 X）、來回搖擺擺幅、平面旋轉、彈跳分頁、Z 軸分頁、光效分頁（明暗與掃光）。

**所有動畫共用**：素材圖片、製作模式、厚度、外形分頁、鑽石分頁、Spine 版本。外形與鑽石分頁最上方有提示。

動作可選：

| 動作 | Spine 裡的效果 |
|---|---|
| 整圈旋轉／整圈旋轉（反轉） | 轉一整圈，可循環；反轉往另一個方向 |
| 正面 → 背面／（反轉） | 半圈，停在背面 |
| 背面 → 正面／（反轉） | 半圈，停在正面 |
| 來回搖擺 | 擺向一側 → 回正 → 擺向另一側 → 回正，可循環；擺幅在常用設定設定 |

整圈與來回搖擺使用「一圈 秒」；半圈使用一半時間。舊的編輯檔打開會自動變成原本的三個動畫（rotate_loop、flip_to_back、flip_to_front），匯出內容與以前相同。新的範例與空白專案則從一個整圈旋轉開始。

可直接開啟 [多動畫範例](examples/irregular-v1.10/animations-v1.14.spturn)。它包含翻轉彈跳、不同軸的反向翻轉與平面旋轉、來回搖擺及反向半圈。免安裝包的 `SpineTurnStudio/examples/irregular-v1.10/animation-set-v1.14` 內附三版 Spine 匯入範例與執行資料。動畫名稱不可使用 Windows 保留名稱或以句點結尾，以免全部動畫的 PNG 子資料夾重疊。

「不規則透明輪廓」的網格會沿翻轉軸切割；若有的動畫用 Y 軸、有的用 X 軸，兩組網格都會放進檔案，每個動畫只顯示自己那組，檔案會大一些。


## 介面與操作回饋

按鈕滑入、按下、鍵盤焦點與停用各有不同顯示；背景、素材收合及專注預覽會保留選取狀態。滑鼠停留可查看操作說明。儲存、開啟與素材操作的完成提示顯示在預覽角落，會自動收起，也可點一下關閉；下方狀態列保留完整訊息。

## 預覽、角度與逐格

- 預覽上方可選擇動畫、背景及檢視縮放；**F8** 切換「專注預覽」，讓預覽佔用更大空間。
- 下方可拖曳時間軸，或輸入實際角度後按 Enter／「套用」。完整旋轉為 0–360°，兩個半圈動畫分別為 0–180°、180–360°。
- 點一下預覽後，Space 播放／暫停，左右方向鍵前後逐格，Home／End 到起終點；也可按畫面上的逐格按鈕。
- 檢視縮放只影響畫面，不會改變匯出大小。輸入欄位和對話框保留原本的按鍵操作。

## 保存與匯出

**繼續用本工具編輯：**按「儲存」或 Ctrl+S，保存成 `.spturn`；Ctrl+Shift+S 另存，Ctrl+O 開啟。編輯檔包含原圖與設定，請手動儲存；它與 Spine 的 `.spine` 是不同檔案。

**交給 Spine：**

1. 在底部固定匯出區選擇 Spine **3.8、4.0 或 4.2**，確認提示的完整版本。
2. 按「匯出 Spine 專案…」。勾選「同時建立原生 .spine」且本機 Spine 成功轉換時，才會產生真正的原生專案；否則仍保留 JSON 與圖片。
3. 以相符版本開啟 `.spine`，切到 Animate 模式並選擇 `rotate_loop`；另有 `flip_to_back`、`flip_to_front`。
4. 保留整個輸出資料夾，尤其是 `images`；不要只拿走 `.spine`。需要逐格圖片時，可另外匯出透明 PNG 序列。

目前三個系列對應 3.8.99、4.0.56、4.2.43。請依匯出提示開啟；例如將 4.2 JSON 匯入 4.0 可能遺失網格動畫，需要 4.0 時應回本工具選擇 4.0 再匯出。

## 修改原始碼後的打包

- `重新打包EXE_測試版.bat`：先執行單元測試，通過後產生獨立的 `dist/dev/時間戳/` 測試版；不代表已通過正式原生相容驗證。
- `重新打包EXE_正式版.bat`：使用目前版號及本地驗證紀錄，通過來源、單元、原生與公開範例檢查後才打包；既有成品同名時會停止，不會覆寫。
- `檢查啟動與打包設定.bat`：只檢查來源、環境與輸出位置，不啟動程式或產生成品。

`.build` 是本機環境與建置資料；`output` 等使用者資料夾會在管理器更新時保留，不應混入公開發行內容。更多參數、外形限制及打包規則請看 [README_zh-TW.md](README_zh-TW.md)。
