# SPINE 資訊檢測工具｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

掃描骨架、網格與相關資源資訊，依自訂門檻標示需檢查的素材，匯出 QC CSV。

## 環境與啟動

Windows 開啟 `dist/SpineQC工具.exe`。純 JSON 可直接掃描；SKEL／SKEL.BYTES 需本機合法可用的 Spine.exe 與對應版本。

## 操作步驟

1. 選擇專案資料夾；含二進位骨架時指定 Spine 執行檔。
2. 在標準值設定填入團隊門檻；留空代表不比對，不是零容忍。
3. 按「開始掃描」，查看紅底／驚嘆號標記；可點欄位排序，必要時停止。
4. 核對結果後按「匯出 CSV」，把來源版本與檢查標準一同交給同事。

## 輸出與保存

表格與 CSV 檢測報告，不會自動優化骨架或減少網格。原始素材應獨立保留。

## 常見問題與限制

- DrawCall 只是依 slots blend 變化的粗估，不含完整頁面、可見性與引擎批次；正式效能用引擎 Profiler 量測。
- 二進位檔讀失敗先確認 Spine 版本／CLI，而不是任意更改副檔名。
- 紅色警告表示超過你填的門檻，不代表一定無法使用。

## 驗收檢查

先掃一份已知骨架，核對骨骼／網格資訊，再掃整包；CSV 記錄是否含失敗列也要確認。
