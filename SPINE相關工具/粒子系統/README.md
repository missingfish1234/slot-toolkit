# SPINE 粒子系統（Particle Studio）v1.25

用瀏覽器離線編排 Spine 粒子特效，輸出 Spine 3.8／4.0／4.2 動畫與圖片；支援 In／Loop／Out 三段演出與既有骨架掛接。

- **開啟**：雙擊 `啟動粒子工作室.cmd`，或直接開啟 `dist/Particle-Studio.html`；不需要伺服器或網路。工作包管理器按「開啟」也是開啟後者。
- **操作**：先看 [使用指南](使用指南.md)（依工作流程撰寫，含快捷鍵與版本紀錄）；完整參數與轉換流程見 [使用說明.txt](使用說明.txt)。
- **轉換 `.spine` 工程**：需另裝對應版本的 Spine 編輯器，本工具不附帶。

## v1.25 重點

輸出時自動烘焙、拖放載入、完整快捷鍵、游標縮放到 800%、圖層單獨顯示／預覽隱藏、每層開始時間與「圖層時間」拖曳、內建效果與我的效果合併、批次輸出多版本與配色變體、參數區塊可收合。未設定開始時間的舊專案，烘焙與輸出結果與 v1.24 完全相同。

## 開發

可編輯來源是根目錄的 `index.html`、`styles.css` 和各 JavaScript 檔。安裝 Node.js 後：

- `node scripts/build.js`：重新產生單檔離線版 `dist/Particle-Studio.html`
- `npm test`：執行單元測試
- `node scripts/build-release.js`：產生並驗證下載包 `dist/Particle-Studio-v<版本>.zip`

舊版下載包移到 `_封存/舊版發佈包/`；測試、分析與交付草稿不包含在下載包內。

## 技術備註

烘焙品質 `fine`、`standard`、`compact` 是選填專案欄位；未設定的舊專案保留既有輸出。品質只調整匯出曲線精簡與補採樣門檻，不改取樣模擬、亂數或生命週期。`ParticleCore.estimateCost` 使用有界的粒子池資料估算補採樣前的成本，實際 KEY 數與 JSON bytes 由試烘焙後的輸出取得。新品質設定匯出適用 2,000,000 取樣限制；估算上限本身不直接拒絕烘焙。

介面設計以日常編輯的便利與直覺性為優先：保留常用控制項的順序，新增功能按需啟用，較少用的選項預設收合。切換模式會保留原值，停用欄位須在所在分頁解釋原因；拖曳紅點或數值不重設捲動位置。新增功能不應要求使用者先理解烘焙的實作細節才能操作。
