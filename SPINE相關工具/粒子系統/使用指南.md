# SPINE 粒子系統使用指南

開發者：小魚骨頭

Particle Studio 用來製作、預覽 Spine 粒子特效，並輸出 Spine 3.8／4.0／4.2 的動畫資料與圖片。所有運算都在本機進行，不需要網路。

> 這份指南以「要做什麼」為順序。各參數細節與轉換流程請看 [使用說明.txt](使用說明.txt)；各版更新內容放在最後的「版本紀錄」。

## 開啟工具

下載後請先**完整解壓縮**，然後選一種方式開啟：

- 在工作包管理器按「開啟」
- 雙擊 `啟動粒子工作室.cmd`
- 直接開啟 `dist/Particle-Studio.html`

建議用 Chrome 或 Edge。單一 HTML 就能使用；若要用範例、轉換器與授權文件，請保留整個資料夾。

## 三分鐘上手

1. 按左側 **「新增效果」**，在效果庫雙擊一個效果（例如「迸射火花」），就會加成新圖層。
2. 在右側 **發射／外觀／運動** 三個分頁調整參數，畫布即時預覽。
3. 想讓這層晚一點出現：在時間軸下方的 **「圖層時間」** 把色條往右拖。
4. 按 **「輸出 Spine」**（或 Ctrl＋E）。參數有修改時會自動重新烘焙，再下載 ZIP。
5. 解壓縮後，在 Spine 用「File → Import Data」匯入 JSON，Images 指向同層的 `images/`。

記得按「儲存專案」（Ctrl＋S）保留 `.particle.json`，之後可用「開啟」（Ctrl＋O）接續編輯。

## 常用操作

### RESET／建立新專案

按上方專案操作列的 **「RESET／新專案」**，選擇：

- **儲存後新建**：先下載目前的 `.particle.json`，再建立新專案。
- **直接新建**：清除目前未儲存的修改，回到初始設定。
- **取消**：繼續編輯目前專案。

新專案名稱為「未命名專案」，保留一層預設金色粒子供編輯。舊粒子圖層、圖片、背景、Spine 掛接、動畫段落、時間軸、視角、參數面板與復原紀錄都會重設；已儲存的專案檔與「我的效果」會保留。新的初始設定會立即存成草稿，重開工具即可接續新專案。

### 新增與管理圖層

- **新增效果**：開啟效果庫。內建效果與「我的效果」放在同一處；雙擊卡片或按「新增為新圖層」加入，「套用至目前發射器」會保留目前圖層的名稱、位置與掛接。
- **＋ 按鈕**：快速新增一層柔光粒子。
- **儲存到我的效果**：在效果庫輸入名稱後按「儲存目前發射器」。效果庫存在目前瀏覽器，請用「匯出效果庫」備份；換電腦時匯入 `.fx-library.json`。
- **複製／貼上圖層**：Ctrl＋D 在同專案複製；Ctrl＋C／Ctrl＋V 可以把圖層貼到另一個專案或另一個視窗。
- **單獨顯示／預覽隱藏**：圖層右下角的「S」與眼睛圖示，或快捷鍵 S、H。只影響畫布預覽，不會改變輸出。
- 每個專案最多 8 個圖層；輸出時依圖層順序疊加。

### 拖放檔案

把檔案直接拖進視窗：

| 拖入的檔案 | 結果 |
|---|---|
| 1 張 PNG／JPEG／WebP | 選「粒子貼圖」、「物件輪廓」（沿外形發射）或「參考背景」 |
| 多張圖片 | 選「連續圖」（依檔名順序播放）或「隨機圖片」（每顆隨機一張） |
| `.particle.json` | 開啟專案 |
| `.fx-library.json` | 匯入效果庫 |
| Spine 匯出資料夾 | 一次載入骨架、角色圖片或圖集（可直接寫回） |
| Spine 骨架 JSON／`.atlas` | 開啟掛接設定並載入 |

### 背景參考圖轉 JPG

1. 在畫布下方按 **「背景轉 JPG」**，選擇 PNG、JPG 或 WebP 背景圖。
2. 在「背景圖片轉 JPG」調整 **「JPG 品質」**（30–100%，預設 88%）及 **「透明區域底色」**。透明區域會先填底色，再轉成 JPG；預覽可確認畫面與原始寬高。
3. 按 **「下載 JPG」** 另存轉換結果，或按 **「套用為參考圖」** 載入畫布。原始檔案會保留。

轉換維持原解析度，2440 × 1440 圖片轉換後仍是 2440 × 1440。來源檔案上限 **32 MiB**、單邊最多 **8192 px**、總像素最多 **16 Mi 像素（約 1678 萬像素）**。結果超過 **4 MiB** 時會自動降低 JPG 品質；仍超過限制時會明確提示先裁切或自行縮小來源圖，工具不會自行縮圖。

使用一般 **「載入參考圖」** 時，來源超過 4 MiB，或轉換後的 PNG 超過大小限制，也會自動開啟這個對話框。JPG 轉換只用於背景參考圖；粒子貼圖繼續保留 PNG 透明度。背景僅供畫布與路徑編輯對照，不加入 Spine 輸出。

### 安排每層的出現時間

- 時間軸下方的 **「圖層時間」**：每層一條色條。實心段是發射期間，淡色細線是粒子最晚存活到的時間。
- 拖曳色條調整 **開始時間**，拖右端調整 **發射時間**；預設對齊整幀，按住 Alt 可自由拖曳；選取色條後用方向鍵逐幀微調。
- 也可在「發射 → 數量與生命」直接輸入開始時間。
- 範例：先 0 秒爆發金幣，0.3 秒後灑金粉，1 秒後補閃光，就能排出 Big Win 的層次。

### 網格閃電

1. 「新增效果」→ 效果庫雙擊「網格閃電」。要用自己的閃電圖，到「外觀 → 粒子貼圖」按「載入圖片」（橫向圖由左到右、直向圖由上到下當作起點到終點）。
2. 在「發射 → 網格閃電」選 **兩端固定**（電弧）或 **尾端擺動**（雷擊）。拖畫布上的藍色端點調長度與方向。
3. 調 **扭曲幅度**、**鋸齒程度**、**變化速度**；需要更熱鬧時加 **同時條數** 與 **分岔**；**粗細跳動**、**亮度跳動**、**閃斷機率** 讓放電更有節奏。
4. 「數量與生命」的開始時間與持續時間決定閃電出現的區間。
5. 輸出時每條閃電是一個網格附件，形狀以逐格網格變形切換，Spine 3.8／4.0／4.2 都可用；也能用「點角色加效果」掛到既有骨架並寫回。

### 外觀：貼圖、連續圖、顏色與曲線

- **粒子貼圖**：「外觀 → 粒子貼圖」載入圖片，或直接拖進視窗。
- **隨機圖**：按「載入隨機圖」一次選多張圖片，每顆粒子出生時隨機挑一張、整個生命不換圖，適合金幣＋寶石混噴或多款碎片。挑選結果跟著發射器種子，按「換一組」重新分配。
- **連續圖**：一次選多張圖片，依檔名數字排序；連續圖 FPS 可設 1–120，並選循環或播放一次。最多 120 張，每張不超過 4 MiB／2048 像素，專案素材合計不超過 16 MiB。各張請用相同畫布與中心，避免跳動。
- **配色與曲線預設**：顏色、透明度、尺寸、速度各有預設，按「套用」才會修改；套用後仍可拖節點與貝茲控制柄。
- **分別調整 X／Y**：尺寸曲線可拆成寬、高兩條，做拉伸、壓扁效果。

### 運動與路徑

- **發射方向**：指定角度、隨機、中心向外、輪廓向外（法線）。
- **沿路徑移動**：「運動 → 編輯路徑與控制點」，可選圓形、8 字形、S 形、螺旋等貝茲預設；拖藍色控制柄調弧度，按住 Ctrl 只調一側。
- **沿物件外型**：載入透明 PNG，掃描外輪廓作為發射位置或移動路徑。
- **沿路徑方向轉向**：讓貼圖朝向前進方向，可設轉向偏移。

### 沿路徑拉伸與殘影拖尾

**想把一張貼圖彎成整條光帶，不需要先手動切 Mesh。** 工具會自動切網格，將同一張貼圖從路徑起點鋪到終點；適合把直向的能量圖拉成一條彎曲光線。

1. 在 **「外觀 → 粒子貼圖」** 載入自己的原始 PNG。
2. 到 **「運動 → 拖尾表演」**，按 **「把目前貼圖做成路徑光帶」**。目前貼圖與已編輯的路徑會保留，並一次設定單一粒子、整條路徑鋪圖及隱藏頭部。也可從「新增效果」直接加入 **「整條路徑光帶」**。
3. 按 **「編輯路徑與控制點」** 調整曲線。手動設定時，拉伸範圍選 **「整條路徑鋪圖」**、取消勾選 **「顯示頭部粒子」**，並把粒子數設為 **1**，就只會看見一條光帶。
4. 直向長條貼圖的 **「貼圖長邊」** 選 **「直向」**，橫向圖選「橫向」。「自動判斷」會取較長的一邊。需要交換起終點圖樣時勾 **「反轉貼圖」**。
5. 用粒子 **尺寸** 和 **寬度倍數** 調光帶粗細，**彎曲細緻度** 調網格段數，**透明度曲線** 控制整條光帶出現及消失。保留原圖顏色時，起始與結束色都設白色。

開啟 `examples/path-ribbon.particle.json` 可查看單一 S 形光帶。專案內嵌自製的 48 × 112 直向藍光貼圖，動畫長 3 秒，預覽停在 1.2 秒。

想讓光帶 **先拉長、再縮短**：

1. 在 **「運動 → 拖尾表演」** 勾 **「啟用拉伸長度曲線」**，按 **「先長再短」**。
2. 未啟用獨立計時時，曲線橫軸是每顆粒子的 **生命進度 0–100%**，縱軸是長度比例，支援 **0–1000%**。例如生命設 2 秒，三個節點設成「0%／15%」「40%／100%」「100%／5%」，就會在出生時長 15%、0.8 秒時達全長、2 秒時縮到 5%。圖層延後開始時，也從各粒子出生後重新計時。
3. 拖曳節點改拉長及縮短的時機；貝茲可調快慢，階梯可讓長度瞬間切換。選 **「維持全長」** 或關閉長度曲線，可恢復固定長度。
4. 要拉超過 200%，先選取曲線上的節點，再於 **「拉伸長度」** 直接輸入 **250、500 或 1000**。例如把中間節點改成 250%，便會在生命 40% 時拉到 2.5 倍長，之後再縮回 5%；圖表會自動調整縱軸，仍可繼續拖曳節點。

在 **「整條路徑鋪圖」**，長度比例決定從路徑起點覆蓋多少；超過 100% 時，開放路徑沿實際終點方向繼續延長，封閉路徑沿原路徑繼續繞行，縮短時沿原路徑收回。**「跟隨移動拖尾」** 則調整保留多少歷史移動跨度，長度超過 100% 仍受粒子實際走過的歷史限制。長度曲線不會把光帶一起變細，完整貼圖仍會鋪滿當下長度；粗細繼續由尺寸與寬度倍數控制。

`examples/path-ribbon-length.particle.json` 內嵌藍光貼圖，設定上述 2 秒的先長再短表演。開啟時停在 0.8 秒，可拖時間軸比較伸長與縮短。這個範例在粒子生命結束後淡出，方便先觀察長度變化。

想做 **0.5 秒到達、0.65 秒尾巴收完**：

1. 載入貼圖後，到 **「運動 → 拖尾表演」** 按 **「彗星撞擊」**，即可建立這個表演；頭部沿路徑移動，到達後停住，尾巴繼續收縮。
2. 手動調整時，啟用 **「獨立移動／收縮時間」**，將 **「移動到達」** 設為 **0.5 秒**、**「收縮結束」** 設為 **0.65 秒**。兩個時間都從每顆粒子出生時計，代表抵達後再用 0.15 秒收尾。
3. 獨立計時啟用後，長度曲線的橫軸依 **「收縮結束」** 計算，和移動速度分開。可保留「彗星撞擊」的 250% 尾長，或選節點自行輸入更大的長度；0–1000% 的範圍仍可用。

「彗星撞擊」使用 **「跟隨移動拖尾」**，路徑嚴格貼合，粒子生命為 0.65 秒，尾長歸零時頭部也結束。預覽與輸出按移動／收縮時間保留足夠存活時間，並保留生命設定。開啟 `examples/path-comet-impact.particle.json`，可拖時間軸比較 0.5 秒抵達、0.6 秒繼續收尾、0.65 秒頭尾消失。

**反覆調時間後變細的修正（v1.29.5）**：把到達或收縮時間調大再改回，會恢復同一組時間對應的粗細、透明度及路徑表演，不再累積變細。尺寸與透明度曲線仍會隨目前設定的有效時間呈現各自的變化。

若舊專案已被先前版本把生命改大，而且改回時間後仍需恢復原效果，可到 **「發射 → 數量與生命」** 把生命長度改回原值。也可重套 **「彗星撞擊」**，保留貼圖及路徑，重新設定時間與曲線。新版沿用舊案已存的生命值，無法自動判斷原值。

若要的是移動中的尾巴或多張淡出的殘影，使用下列操作：

1. 按「新增效果」，雙擊 **「沿路徑拉伸」** 或 **「殘影拖尾」**，直接加入已設定好路徑的圖層。也可選既有粒子，在「運動 → 路徑與拖尾」啟用拖尾。
2. 按 **「編輯路徑與控制點」**，調整 S 形、圓形、8 字形等路徑，或拖曳控制點畫出自己的彎曲軌跡。停止自轉並開啟沿路徑轉向，殘影貼圖就會朝前進方向。
3. 選擇表演：**沿路徑拉伸** 搭配 **「跟隨移動拖尾」**，讓一張貼圖沿歷史移動軌跡彎曲拉長；**殘影拖尾** 讓多張先前位置的貼圖跟在粒子後方、越往尾端越淡。
4. 調 **殘留時間** 決定尾巴能保留多久；**拖尾透明度** 決定強弱；**寬度倍數** 調尾巴粗細。拉伸模式可調 **尾端收尖**、**彎曲細緻度**；殘影模式以 **殘影數** 決定疏密。
5. 粒子頭部消失後，尾巴會繼續淡出，最多延續一個殘留時間。若動畫末尾被截斷，請增加全域動畫長度；非循環範例已留出收尾時間。
6. 直接按「輸出 Spine」，拉伸輸出為網格變形，殘影輸出為多個圖片附件與透明度動畫。Spine 3.8／4.0／4.2、既有骨架掛接及 In／Loop／Out 都可用；儲存專案與「我的效果」會保留路徑及拖尾設定。

範例：`examples/path-trail-stretch.particle.json`、`examples/path-trail-afterimage.particle.json`，3 秒非循環、圖片已內嵌，可拖時間軸查看頭部消失後的收尾。

### 強化既有 Spine（在做好的動畫上加粒子）

1. 按畫布上方「掛接骨架」，右側會換成「強化既有 Spine」面板（不擋畫布；再按一次或按 × 回到發射器設定）。
2. 按 **「開啟原工程資料夾」**，選 Spine 匯出 JSON 的資料夾；或直接把整個資料夾拖進視窗。骨架、角色圖片（或圖集）會一次載入。
3. 在面板「動畫與時間」選目標動畫（例如 `win`），把時間軸播放頭拖到想出現的那一刻。
4. 按 **「點角色加效果」**（或按 A），在角色圖片上點一下，例如劍尖：
   - 選「在此圖前面／後面」決定前後圖層。
   - 勾「從播放頭開始」，這一層就在目前時間出現。
   - 按「＋ 在這裡新增效果」，從效果庫挑一個；新圖層自動掛在那張圖的骨骼上、放在點擊位置。
   - 或按「把目前發射器移到這裡」，搬移已經做好的圖層。
5. 調整參數；想整段挪動時間，直接拖時間軸上的綠色「粒子」段落，會吸附原動畫的事件（黃色標籤）與關鍵幀，按住 Alt 自由拖曳。
6. 按 **「寫回原工程」**（Ctrl＋E）。原 JSON 會被覆寫、新圖片放進 Images 下的 `particle_fx/`，寫入前自動備份到 `_particle_backup/日期-時間/`。
7. 之後要再修改：重新開啟同一個資料夾，選「接續上次的粒子」，輸出會替換上次那組粒子，不會重複追加。

> 寫回的是 JSON 與圖片。原生 `.spine` 工程請在 Spine 用 Import Data 匯入；使用圖集的專案請重新打包圖集。
> 在 Spine 重新匯出 JSON 後，請重新開啟資料夾再寫回；工具偵測到檔案被改過會停止寫入，避免覆蓋。
> 不支援寫入的瀏覽器會改為下載追加包 ZIP；手動載入 JSON、指定父骨骼與插槽等舊流程收在面板的「手動載入檔案」與下方各區塊。

### 輸出

- **輸出 Spine**：直接按即可，參數有修改時會自動重新烘焙。
- **批次輸出**：一次勾選多個 Spine 版本與配色變體（原色、色相旋轉、配色預設），全部放進同一個 ZIP、每組一個資料夾。變體只改顏色，動態與亂數完全一致。貼圖 PNG 本身不會重新上色，白色或灰階貼圖的換色效果最明顯。掛接既有骨架時請用「輸出追加包」。
- **烘焙檢查**：比較精細／標準／精簡三種品質的 KEY 數與 JSON 大小。
- **In／Loop／Out**：在「動畫段落」開啟三段演出，輸出三個動畫。

## 疑難排解

- **Spine 裡看不到圖片**：確認 JSON 與 `images/`（追加包為 `new_images/` 內的群組資料夾）在正確位置，且使用同一次輸出的 JSON 與圖片。
- **本機草稿不見了**：草稿存在瀏覽器裡，清除瀏覽資料或換瀏覽器就會消失。重要版本請「儲存專案」另存檔案。
- **掛接預覽無法解析**：確認骨架版本是 3.8.99／4.0.x／4.2.x；3.8.75 需先在 3.8.99 重新匯出。
- **`.spine` 工程轉換**：雙擊 `啟動Spine工程轉換.cmd`，電腦需已安裝對應版本的 Spine 編輯器；本工具不附帶 Spine。
- 正式工程匯入前請先備份，並以實際 Spine／引擎畫面驗收。
