# SPINE 粒子系統使用指南

## 用途與啟動

Particle Studio 用於製作及預覽 Spine 粒子特效，再輸出動畫資料與圖片給 Spine 工程使用。下載後請先**完整解壓**。在工作包管理器按「開啟」、雙擊 `啟動粒子工作室.cmd`，或直接開啟 `dist/Particle-Studio.html` 均可。一般編輯不需網路或伺服器；建議用 Chrome 或 Edge。

## 基本流程

1. 開啟工作室，先選擇範例或建立新效果，設定畫布及粒子圖。
2. 調整發射、顏色、大小、速度和時間曲線，使用預覽確認 In／Loop／Out 三段演出。
3. 若需掛接現有 Spine 骨架，匯入對應資料並確認版本及附件／槽位，再預覽合成效果。
4. 匯出所需的 Spine 版本（3.8、4.0 或 4.2）與圖片 ZIP，使用素材副本先到 Spine 或目標引擎核對動畫、透明度及循環點。

## 專案轉換與限制

- `啟動Spine工程轉換.cmd` 是輔助轉換入口；處理 `.spine` 工程需要電腦已有相容版本的 Spine 編輯器。此工具不會自動安裝 Spine。
- 單檔 HTML 可單獨開啟；若要使用範例、轉換器與授權文件，請保留完整資料夾。
- 正式工程匯入前請另存備份。瀏覽器下載位置、素材檔名及引擎設定可能影響最後結果，請以實際 Spine／引擎畫面驗收。

完整控制項、檔案格式、轉換步驟與疑難排解請看 [使用說明.txt](使用說明.txt)。
