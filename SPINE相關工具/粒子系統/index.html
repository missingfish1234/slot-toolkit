PARTICLE STUDIO

從粒子到 Spine 動畫

這是獨立開發的本機粒子編輯器。介面與模擬程式都存放在本機，操作時不需要連線。

  1. 建立效果

    從左側新增發射器，調整發射、外觀與運動參數。即時預覽會顯示修改後的效果。

  2. 檢查時間軸

    暫停、拖曳或逐格播放，確認粒子出生、消失與循環接縫。畫布背景僅供參考。

  3. 更新烘焙

    烘焙把粒子路徑轉成固定幀率的骨骼關鍵幀。修改參數後需要重新烘焙，再輸出 Spine 資料。

  4. 匯入對應版本 Spine

    解開輸出套件，保留 JSON 與 images 資料夾的位置。在 Spine 選擇「檔案 → 匯入資料（Import Data）」載入 JSON，確認 Images 路徑指向素材資料夾。

記得儲存編輯專案

「儲存專案」包含發射器參數與粒子貼圖，可用「開啟」接續編輯。Spine 輸出是動畫交付資料。Atlas 圖集可在 Spine 匯出時產生。

ATTACH TO SPINE

追加到既有骨架

尚未載入原骨架

支援 Spine 3.8、4.0、4.2 的單一骨架 JSON；追加輸出自動跟隨原骨架版本。原生 .spine 請先用離線包附帶的「Spine 工程轉換」，或在對應版本 Spine 匯出 JSON 並勾選 Nonessential。

原骨架預覽素材

尚未載入角色圖片；預覽會顯示骨架與粒子。

原始圖片請選擇原 Images 根資料夾，保留 body/head.png 等子目錄。若使用圖集，請載入 .atlas 及對應 PNG 頁面。每張圖片上限 4 MiB、2048 像素，內嵌素材合計上限 16 MiB。

掛接位置

粒子的 X/Y 以父骨骼為原點，會跟隨骨骼的移動、旋轉與縮放。

各發射器分別掛接

追加表演

追加一段目前烘焙長度的粒子表演，段落結束後隱藏；原動畫的骨骼與其他表演軌保留。

三段表演掛接

IN · 進場

LOOP · 循環

OUT · 退場

三段使用相同粒子骨骼與素材。LOOP 從 0 秒循環，在完整循環邊界接 OUT；原 LOOP 動畫不可長於粒子 LOOP。

前後圖層

Spine 以插槽決定前後順序；父骨骼與圖層可以分開指定。

畫布依原骨架動畫預覽粒子掛接位置；未載入或缺少圖片時會顯示骨架與粒子。請載入原素材確認角色外觀，並在 Spine 檢查最終輸出。
ANIMATION FLOW

In / Loop / Out 動畫段落

三段共用同一組粒子骨骼；每段可設定自己的長度與輸出動畫名稱。

IN

進場

淡入並銜接 Loop 的循環畫面。

LOOP

循環

持續發射，可反覆播放完整一輪。

OUT

收尾

停止發射，存活粒子繼續移動並淡出。

Out 以 Loop 完整一輪結束的狀態銜接。若遊戲在任意時點切換 Out，需要安排到循環結束，或另外設定動畫混合。

追加原工程時，可在「掛接骨架」為三段分別選擇既有動畫或建立新動畫。
