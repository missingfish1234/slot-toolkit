粒子工作室 Particle Studio v1.9
支援版本：Spine Editor 3.8、4.0、4.2
預設輸出：3.8.99／4.0.56／4.2.43

開啟工具
雙擊 dist 資料夾中的 Particle-Studio.html，以新版 Chrome 或 Edge 開啟。
也可以雙擊同層「啟動粒子工作室.cmd」，交由預設瀏覽器開啟。
這個單一 HTML 已包含介面與程式，操作時不需要網路或本機伺服器。
原始碼模式也可以直接開啟 index.html，但同層程式與樣式檔需要完整保留。

新版介面
深墨色與薄荷青工作台：效果圖層以卡片呈現，顯示形狀圖示、圖層序號及粒子色點。
發射器參數分組、分頁圖示與輸出狀態更清楚；主要欄位與文字放大，畫布和播放控制保留獨立區域。
視窗較窄時，畫布、發射器與參數區改為上下排列；可以捲動繼續操作。
所有舊版專案、曲線、數值拖曳與 Spine 4.0.56 輸出功能皆可沿用。

選擇 Spine 輸出版本
左上角「輸出版本」可選 SPINE 3.8、4.0、4.2，選擇會保存於專案及本機草稿。
舊專案未指定版本時，沿用 4.0.56。改輸出版本會重新產生對應 JSON，不改粒子參數或軌跡。
3.8 使用 color 與 rotate.angle；4.0／4.2 使用 rgba 與 rotate.value；不是單純改版本標籤。
3.8 大角度旋轉會補入必要關鍵幀，避免 runtime 的最短角度插值省略整圈旋轉。
「掛接骨架」啟用時，選擇器顯示「跟隨骨架」並鎖定原骨架的完整版本；移除或停用掛接後恢復獨立輸出版本。
追加只把新粒子輸出為原骨架的版本，不會把原角色升級或降級；要轉換原角色版本，請在官方 Spine 編輯器另行處理。
官方 runtime 不接受 3.8.75 資料，該版本需在 3.8.99 重新匯出後使用。

編輯效果
In / Loop / Out 三段動畫
按動畫設定列的「動畫段落」，勾選「啟用三段動畫」。In、Loop、Out 各有獨立的動畫名稱及長度，範圍 0.05–30 秒；長度欄位可左右拖曳。
In 以預熱循環畫面淡入，結尾對齊 Loop 起點；Loop 依發射器的數量、發射時間、生命曲線等設定反覆播放；Out 停止新生粒子，存活粒子繼續移動並淡出，最後完全隱藏。
若需要 Loop 整段持續有粒子，請將發射器的「發射時間」設為 Loop 長度，並調整粒子數與生命長度；短發射時間仍可用於每輪反覆出現的爆發效果。
三段共用同一套骨骼、插槽與圖片，不會產生三套重複粒子。背景參考圖仍不輸出。
按「更新三段烘焙」後，畫布上方可分別選 IN／LOOP／OUT 檢查；「串接試播」會先播 In，再反覆 Loop。
按「結束 Loop」，會等目前完整一輪結束再播放 Out，最後停止。單獨預覽 In 或 Out 時，只播放一次。
獨立輸出的骨架 JSON 內含三個動畫，套件「動畫段落.json」記錄各名稱、長度與循環設定。匯入 Spine 或遊戲後，請將 Loop 設為循環，In 與 Out 設為單次播放。
Out 只保證在 Loop 完整一輪的邊界銜接；遊戲任意時點立即切換 Out，需要安排到循環結束，或自行設定動畫混合。
保證銜接的是粒子的局部狀態。掛接原骨架時，原父骨骼在 In／Loop／Out 三個原動畫中的姿態也需連續。
勾選掛接後，「三段表演掛接」可為 In、Loop、Out 分別追加到原動畫或建立新動畫，In 與 Out 可各設定開始偏移時間。
Loop 固定從 0 秒開始；原 Loop 長度大於粒子 Loop 時會阻擋輸出，請加長粒子 Loop 或選擇新動畫。原 Loop 較短時，會保留原軌並延長動畫至粒子 Loop 長度。
原本的單段模式可繼續使用：取消「啟用三段動畫」即可，三段設定會保留。三段專案請用 v1.7 或更新版本開啟。
超短 Loop、很長 In 與大量粒子會增加取樣與 KEY；匯出前估算超過 200 萬取樣會先停止，請減少粒子、縮短 In 或延長 Loop。

單段與發射器編輯
1. 左側選擇效果類型，按「＋」新增發射器，可複製、刪除或調整圖層順序。
2. 右側「發射／外觀／運動」調整參數、貼圖與曲線；拖曳曲線控制點調整生命期間變化。
3. 點選紅色控制點選取發射器，直接拖曳調整位置，X／Y 欄位同步更新；拖曳空白區移動視角，滾輪縮放。
   選取紅點後可用方向鍵微調 1 px，Shift＋方向鍵移動 10 px；「置中發射器」設為 X=0、Y=0。
   停用發射器仍可調整控制點位置。控制點操作後需更新烘焙再輸出。
4. 使用播放、逐格與時間軸檢查效果。X 向右為正、Y 向上為正。
   外力「風向」：正值向右吹、負值向左吹；「重力」：正值向下、負值向上；0 表示無此外力。
   兩者以 px/秒² 表示，絕對值越大作用越強，皆可左右拖曳調值。
   舊專案的角度式風力會換算成等效的左右風向與上下重力，保留原本的軌跡。
5. 背景參考圖僅供畫布對照，不會作為 Spine 粒子輸出。

拖曳數值欄位
滑鼠按住數值欄位中央後左右拖曳：向右增加、向左減少，不必按在小箭頭上。
Shift 為 10 倍速度；Alt 為慢 10 倍，可精細調整，數值仍遵守欄位步長及上下限。
普通點擊後可直接鍵入數字，右側原有小箭頭也能使用；短於 4 px 的位移不會調值。
拖曳途中按 Esc 可恢復原值。位置、角度、線長、生命、速度、動畫長度和種子等數值欄位皆可拖曳。
拖曳時預覽持續更新，放開滑鼠後會保存草稿。若已烘焙，修改後需重新更新烘焙再輸出。

新增形狀設定
形狀與發射位置分開設定：先選長方形、圓形或圓環，再用「發射位置」選「區域內」或「輪廓線上」。
「區域內」讓粒子從形狀的內部區域出生；「輪廓線上」只從邊界出生。長方形的四條邊依邊長分配粒子，不會只集中在角落；圓環輪廓會遵守設定的弧段範圍。
要做長方形外框粒子：選「長方形」→「輪廓線上」，調整寬／高，再按「更新烘焙」。若希望粒子留在框線上，將速度及速度隨機、重力、風向設為 0；若有速度或外力，粒子出生後仍會依原運動設定移動。
舊專案未指定發射位置時，長方形／圓形沿用區域內，圓環沿用輪廓線；保持原本的隨機種子、發射位置與軌跡。新發射位置選項會保存於專案與草稿，請使用 v1.9 或更新版本編輯。
線形：可設定「線長」（0–2000 px）與「線段方向」。線段以紅色控制點為中心，0° 水平、90° 垂直。
圓環：寬高控制圓／橢圓尺寸；「圓環範圍」360° 是完整圓環，120° 是指定弧段。
「弧段中心方向」0° 向右、90° 向上；例如中心 90°、範圍 120°，即朝上、左右各 60°。
區域的方向與粒子的「發射方向／散射角」可分開調整。
舊專案可以直接開啟；新增的線形與圓環弧段請使用 v1.1 或更新版本的工具編輯。

生命週期顏色與透明度
「外觀」中的漸層上排是透明度節點，下排是顏色節點；中間棋盤底顯示實際 RGBA 變化。
按「＋透明度／＋顏色」新增節點，點選節點後可左右拖曳生命位置，或在下方欄位輸入百分比、顏色或透明度。
每排最多 32 個節點；0% 與 100% 端點固定位置，中間節點可用垃圾桶或 Delete 刪除。
透明度節點與下方透明度曲線共用資料，任何一處修改都會同步；透明度 0 完全透明，1 完全不透明。
顏色在相鄰節點之間漸變，透明度可另外使用貝茲或階梯曲線。RGB 顏色與 Alpha 可設定不同數量、不同生命位置的節點。

貝茲與速度曲線
透明度、尺寸與速度曲線皆可選擇「線性／貝茲／階梯」。先選節點，再設定該節點之後的曲線段；選最後端點時設定最後一段。
選「貝茲」後，拖曳藍色菱形控制柄調整彎曲程度；金色圓點控制生命位置與數值。點擊曲線空白處新增節點，右鍵或 Delete 刪除中間節點。
下方生命位置與倍率欄位也支援左右拖曳、Shift 加速、Alt 微調，以及拖曳途中 Esc 恢復。
「運動」頁勾選「啟用速度曲線」，或直接編輯速度圖表，將使用自訂速度倍率曲線；1 為初始速度、0 停止、2 為兩倍，範圍 0–4。
速度會沿生命期間累積成實際位移；重力及風力仍依時間作用。啟用速度曲線會覆蓋「移動節奏」，取消勾選或重設速度曲線可回到原設定。
取消勾選會保留自訂曲線，儲存並重開專案後仍可重新啟用；「重設」才會清除自訂速度曲線。
曲線控制柄與多段顏色會保存於 .particle.json；Spine 輸出採取樣烘焙的關鍵幀，以兼容 3.8、4.0、4.2，請修改後更新烘焙。
舊版專案會保留原本的起始／結束色及移動節奏；使用新增功能的專案請以 v1.3 或更新版本開啟。

保留編輯進度
工具會嘗試在目前瀏覽器保存並恢復本機草稿；瀏覽器設定、清除資料或更換檔案位置，可能使草稿不可用。
請另外按「儲存專案」下載 .particle.json 檔。它包含參數、貼圖、背景與已烘焙快照，可用「開啟」接續編輯。
建議重要版本另存不同檔名。本機草稿不等於另存專案檔。
快捷鍵：Ctrl+S 儲存專案；未輸入參數且未聚焦紅點時，空白鍵播放／暫停，左右方向鍵逐格檢查。

烘焙與輸出
「即時預覽」反映目前參數；「更新烘焙」產生固定幀率的骨骼與關鍵幀，並切到烘焙結果。
修改粒子參數後會顯示「待更新烘焙」，重新烘焙後才能輸出，避免交付舊效果。
按「輸出 Spine」下載 ZIP，解壓縮後保留以下內容：
  專案名稱.json            所選版本的 Spine 動畫資料
  images/                  粒子 PNG 素材
  專案名稱.particle.json   本工具的編輯專案
  匯入說明.txt              該次輸出的設定與匯入指引

匯入對應版本 Spine
1. 解壓縮 ZIP；保留 Spine JSON 與 images 資料夾的相對位置。
2. 在 Spine 使用「檔案 → 匯入資料」（File → Import Data），選擇專案名稱.json。
3. 確認 Images 路徑指向同層的 images/ 資料夾，播放 effect 動畫；循環效果需開啟循環播放。
4. 存成新的 .spine 專案。需要圖集時，在 Spine 匯出流程建立 atlas。
5. 若要整合到既有角色／特效，先保存新 .spine 專案，再使用 Import Project 匯入並檢查骨骼、動畫與素材名稱。

追加至既有 Spine 骨架
1. 畫布上方按「掛接骨架」，載入原工程的 Spine 3.8、4.0 或 4.2 JSON。原生 .spine 請先用本包的「啟動Spine工程轉換.cmd」轉成 JSON，或在對應版本 Spine 匯出 JSON，勾選 Nonessential。
2. 選「預設父骨骼」。可搜尋骨骼名稱，也可展開「各發射器分別掛接」，把不同發射器指定到不同骨骼。
3. 選「追加至原動畫」或「新增動畫」，設定開始時間。原表演保留，新增粒子只播放目前烘焙長度的一段，結束後隱藏。
4. 設定最前方、最後方或指定插槽之後。父骨骼控制移動；插槽控制前後圖層，兩者分開設定。
5. 更新粒子烘焙，再按「輸出追加包」。載入且啟用掛接時，上方輸出按鈕也會改成追加包；取消「啟用追加輸出」可繼續輸出獨立特效。
6. 將追加包 new_images/ 裡的群組資料夾複製進原工程的 Images 根目錄。它使用唯一的名稱，避免新增圖片與原素材相撞。原角色圖片、atlas、音效請繼續保留。
7. 將合併 JSON 放在原骨架 JSON 的同層，維持原 Images 相對路徑。用 Spine Import Data 匯入，或用轉換工具產生新的 .spine，再播放目標動畫檢查，另存新版本。

掛接座標與保存
X/Y 為父骨骼的局部座標，粒子整個群組會隨父骨骼平移、旋轉、縮放；不是發射後留在世界座標的粒子。
啟用掛接後，畫布可切換「掛接預覽」或「粒子單獨」。掛接預覽使用對應版本官方 Spine runtime，粒子會跟隨原動畫的骨骼，包含 IK、transform/path 約束與不同骨骼繼承模式。
掛接預覽的時間軸是完整目標動畫的時間：例如原動畫 4 秒、粒子開始 1.5 秒、粒子長度 1.2 秒，畫布會播放 0–4 秒，粒子只在 1.5–2.7 秒出現；原骨骼從 0 秒持續表演。
三段掛接時，各段也使用對應目標動畫的完整時間。In 在開始偏移前隱藏，粒子 In 結束後保留尾端姿態直到原 In 完成；Out 的粒子退場後隱藏，原 Out 剩餘時間仍會播放。串接試播會依這個完整時間切換各段。
按「跳到粒子開始」可直接檢查開始位置；「對焦掛接點」與對話框「定位掛接骨骼」會將目前選取發射器的父骨骼移到畫布中心。「骨架」開關控制骨骼線，Skin 選單可切換原皮膚。
紅色發射器控制點會跟隨父骨骼。拖曳時工具將畫布上的移動換算回父骨骼局部 X/Y，包含旋轉、縮放與鏡像；拖曳時暫停表演，放開後需重新烘焙再輸出。
若父骨骼縮放為 0 或無法反算局部位置，控制點會提示無法拖曳；請調整時間或用 X/Y 欄位修改。
新增動畫沒有原角色骨骼軌時，掛接預覽使用原骨架的 setup pose；選追加原動畫才能預覽該動畫的骨骼表演。
原 JSON 的骨骼、插槽、皮膚、約束、事件、動畫軌與圖片路徑保留；原 drawOrder 軌會調整偏移索引，以維持原角色各圖層的相對順序。
新增群組若重名會自動加後綴。新動畫名稱若與原動畫重名，介面會阻擋輸出，避免將新動畫誤追加到既有動畫。
「儲存專案」與本機草稿包含原骨架 JSON、掛接設定及已載入的角色預覽素材，下次開啟不必重新選父骨骼或素材。
JSON 往返只能保留已匯出的資料，未匯出的編輯器資料無法由本工具還原；請一直保留原 .spine 工程。

掛接預覽素材
「掛接骨架」對話框的「原骨架預覽素材」可載入多張 PNG、JPEG 或 WebP；素材會轉成 PNG 供本機預覽。
原始圖片含子目錄時，請按「選擇 Images 資料夾」，選原工程 Images 根資料夾。工具只移除所選根資料夾名稱，保留 body/head.png 等相對路徑，以對應原骨架附件。
若原工程使用 atlas，按「載入 Atlas 圖集」選 .atlas 純文字檔，再載入對應的 PNG 頁面；多頁圖集需要載入所有頁面。
已存在的圖片相對路徑不會被覆蓋；如需更換素材，先按「清除預覽素材」，再載入正確的資料夾或圖集。
未載入或缺少角色圖片時，骨架與粒子仍可預覽，狀態列會列出缺圖；缺圖不代表角色沒有該附件，也不影響原骨骼跟隨。
每張素材檔案及轉換後 PNG 上限 4 MiB；預覽圖片最多 2048 像素，過大的圖片會依比例縮小。內嵌預覽素材合計上限 16 MiB；Atlas 純文字上限 256 KiB。
原角色素材只供預覽及編輯專案保存，不會重複加入 new_images/；追加輸出仍沿用原素材路徑，原工程圖片、atlas 與音效需自行保留。
畫布支援 region、加權 mesh、deform、clipping、drawOrder 與常見混合模式。正式交付請繼續在 Spine 及目標遊戲檢查最終外觀。
Spine 4.2 的圖片 Sequence 附件會依原動畫選擇目前影格；請載入完整的影格圖片或對應圖集。v1.9 同時包含 Sequence 讀取修正，缺少圖片時仍可檢查骨架與粒子的位置。
Spine 4.2 的 Physics 物理約束目前不支援掛接預覽。含 Physics 的骨架會顯示明確提示，請切回「粒子單獨」；追加輸出仍完整保留原 Physics 資料。

Spine 工程轉換工具
雙擊「啟動Spine工程轉換.cmd」，選 .spine 會輸出 _particleSource.json；選合併 JSON 會匯入成新的 _particles.spine。
需要本機已安裝 Spine.com，並已在官方 Spine 啟動過要使用的版本，使該版本存在本機快取。轉換工具不安裝或下載版本。
原生 .spine → JSON 時，選擇原工程所用的 3.8／4.0／4.2 版本；JSON → .spine 自動使用 JSON 的完整版本號，避免誤升級或降級。
命令列原生工程匯出可指定 -SpineVersion 3.8.99、4.0.56 或 4.2.43；省略時沿用 4.0.56。
預設使用 C:\Program Files\Spine\Spine.com。其他位置可在腳本命令列傳入 -SpinePath。
原檔與既有輸出不覆蓋；預設遇重名加後綴。轉換只支援單一骨架，多骨架工程請在 Spine 中選擇目標骨架匯出。
產生的圖片路徑沿用原設定；若搬到不同資料夾，請在 Spine 調整 Images 路徑。GUI 選檔流程由使用者操作；CLI 往返已在 3.8.99、4.0.56、4.2.43 實測。

使用範圍
這是獨立開發的粒子編輯工具，透過烘焙產生可編輯的骨骼動畫。
大量粒子或長壽命會增加骨骼與關鍵幀數；請依交付規格控制粒子量。
目前遊戲 runtime、PMA（預乘 Alpha）、圖集設定與動畫混合／中斷尚未完整驗證，正式交付前需在目標遊戲測試。
整合到既有 Spine 工程時，請使用匯入流程並檢查素材路徑與圖層順序。
Spine 動畫 JSON 與其他工具的參數檔不能直接當作本工具的 .particle.json 專案開啟。
本機骨架預覽內嵌 Esoteric Software 的官方 Spine Runtimes，授權與版權聲明見 assets/spine-runtime-licenses.txt；同一聲明亦保留於離線 HTML。

附帶範例
examples/border-emission.particle.json 展示形狀與發射位置分開設定，可開啟後切換「區域內／輪廓線上」比較出生位置。
examples/attached-preview.particle.json 包含自製的動畫骨架、IK、mesh 與內嵌圖片，粒子掛在 hand、lower 與 noScale 骨骼下；原 main 動畫 4 秒、粒子開始 1.5 秒，開啟時停在 1.8 秒，可直接拖曳紅點或切回 0 秒檢查開始偏移。
examples/attached-preview-flow.particle.json 是同一測試骨架的三段掛接範例，包含原 existingIn／existingLoop／existingOut 動畫與獨立的 In／Out 偏移；可使用串接試播檢查完整動畫時序。
examples/in-loop-out.particle.json 展示 FX_In 0.6 秒、FX_Loop 1.2 秒與 FX_Out 0.7 秒；三段共享 64 個粒子骨骼。
examples/in-loop-out_spine3.8.zip、in-loop-out_spine4.0.zip、in-loop-out_spine4.2.zip 為同一示範的三版本實際工具輸出套件。
examples/golden-dust.particle.json 可用本工具「開啟」接續編輯。
examples/golden-dust_spine4.0.zip 是可搬移的 JSON + images 套件，已通過實際 Spine 4.0.56 匯入與素材打包。
examples/line-and-arc.particle.json 展示 300 px／30° 線形與朝上的 120° 橢圓弧段，可點選兩個紅點切換、拖曳及修改數值。
examples/line-and-arc_spine4.0.zip 是該示範的 Spine JSON + images 套件。
examples/lifetime-gradient.particle.json 展示多段顏色、獨立透明度與貝茲速度／尺寸曲線。
examples/lifetime-gradient_spine4.0.zip 是通過實際 Spine 4.0.56 匯入驗證的對應套件。
examples/lifetime-gradient_spine3.8.zip 與 examples/lifetime-gradient_spine4.2.zip 是實際工具輸出的對應版本套件，已通過各版本官方 runtime 的位置、旋轉、透明度與顏色比對。
examples/attach-to-existing.particle.json 包含原骨架、粒子與掛接設定，展示把粒子掛在 hand 下、0.4秒追加到 main 動畫、放在 handSlot 之後。
examples/attach-to-existing_spine4.0.zip 包含示範原骨架、合併結果與完整示範素材，可直接依說明匯入Spine4.0.56；示範的原骨架JSON為examples/attach-to-existing.json。
原始碼工作區另附 examples/golden-dust.spine，可在目前資料夾直接開啟（未放入離線版 ZIP）。若要搬移此工程，先在 Spine Editor 將 Images 的 Path 設成 ./images/ 再存檔；Spine 4.0 CLI 建立工程的素材路徑有已知限制。
