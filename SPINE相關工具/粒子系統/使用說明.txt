粒子工作室 Particle Studio v1.26
支援版本：Spine Editor 3.8、4.0、4.2
預設輸出：3.8.99／4.0.56／4.2.43

開啟工具
雙擊 dist 資料夾中的 Particle-Studio.html，以新版 Chrome 或 Edge 開啟。
也可以雙擊同層「啟動粒子工作室.cmd」，交由預設瀏覽器開啟。
這個單一 HTML 已包含介面與程式，操作時不需要網路或本機伺服器。
原始碼模式也可以直接開啟 index.html，但同層程式與樣式檔需要完整保留。

v1.26 多圖隨機粒子
1. 「外觀 → 粒子貼圖」按「載入隨機圖」，一次選多張圖片（最多 120 張，素材合計 16 MiB 內）。
   每顆粒子出生時從中隨機挑一張，整個生命都維持同一張；和「連續圖」依序逐張播放不同。
2. 「貼圖模式」可在「單張圖片」「連續圖動畫 · 依序播放」「多圖隨機 · 每顆隨機一張」之間切換，素材保留。
3. 也可以把多張圖片拖進視窗，放到「隨機圖片」區。
4. 挑選結果由發射器種子決定，可重現；在「發射 → 隨機變化」按「換一組」會重新分配。改成隨機圖不會改變粒子的動態。
5. 圖片大小依最大的一張等比例縮放，小圖仍維持相對大小。輸出到 Spine 3.8／4.0／4.2 時，每顆粒子固定一個附件，不會中途換圖。
6. 適合金幣＋寶石混噴、不同形狀碎片、多款花瓣或星星等效果。

v1.25 操作與量產優化
1. 輸出不必先烘焙：參數改過後直接按「輸出 Spine」（或 Ctrl+E），會自動重新烘焙再下載；追加包同樣適用。
2. 拖放載入：把檔案拖進視窗即可。單張 PNG 可選「粒子貼圖」「物件輪廓」「參考背景」；多張 PNG 依檔名數字排序成連續圖；
   .particle.json 開啟專案、.fx-library.json 匯入效果庫、Spine 骨架 JSON 開啟掛接設定、.atlas 載入圖集。
3. 快捷鍵：Ctrl+O 開啟、Ctrl+B 烘焙、Ctrl+E 輸出、Ctrl+D 複製圖層、Ctrl+C／V 複製貼上圖層（可跨專案與視窗）、
   Delete 刪除圖層、[ ] 切換上下圖層、S 單獨顯示、H 預覽隱藏、F 對焦目前發射器、0 縮放回 100%。完整列表見工具右上「?」。
4. 滾輪以游標位置為中心縮放，範圍 5%–800%。
5. 圖層列的「S」單獨顯示、眼睛圖示「預覽隱藏」：只影響畫布預覽，不改專案、烘焙或輸出。
6. 每層「開始時間」：發射頁「數量與生命」新增開始時間，或在時間軸下方「圖層時間」直接拖曳色條；拖右端調整發射長度，
   預設對齊整幀，按住 Alt 可自由拖曳，方向鍵逐幀微調。未設定開始時間的舊專案，輸出結果與先前完全相同。
7. 效果庫合併：左側「新增效果」開啟效果庫，內建效果與我的效果放在一起，雙擊或按「新增為新圖層」加入；
   「套用至目前發射器」保留名稱、位置與掛接。旁邊的「＋」快速新增柔光粒子。
8. 批次輸出：上方「批次輸出」可一次勾選 Spine 3.8／4.0／4.2 與多種配色（原色、色相旋轉、配色預設），
   全部放進同一個 ZIP、每組一個資料夾。變體只改顏色，動態、亂數與時間完全一致；掛接既有骨架時請改用「輸出追加包」。
9. 參數區塊可點標題收合，工具會記住收合狀態。

新版介面
v1.22.1 修正外觀頁預設選單的隱藏標籤撐高整頁；桌面參數區捲到底時，不再把工具標題與畫布捲出畫面。
各分頁仍保留捲動位置；窄視窗繼續使用上下排列與整頁捲動。
深墨色與薄荷青工作台：效果圖層以卡片呈現，顯示形狀圖示、圖層序號及粒子色點。
發射器參數分組、分頁圖示與輸出狀態更清楚；主要欄位與文字放大，畫布和播放控制保留獨立區域。
視窗較窄時，畫布、發射器與參數區改為上下排列；可以捲動繼續操作。
所有舊版專案、曲線、數值拖曳與 Spine 4.0.56 輸出功能皆可沿用。
v1.10.1 的運動頁先顯示速度、速度曲線與外力；路徑停用時保留簡短入口，可直接編輯，無須先勾啟用。
「更多路徑選項」包含前進方式與疊加外力；「更多輪廓選項」包含閾值、內孔與參考圖顯示，皆預設收合。
路徑使欄位暫停作用時，會在所在分頁說明原因，原參數值保留；發射頁的「調整路徑」會直接定位到相關設定。
發射、外觀、運動各自記住捲動位置；拖曳紅點或數值不重設捲動，停用路徑後恢复原欄位的可用性。

選擇 Spine 輸出版本
左上角「輸出版本」可選 SPINE 3.8、4.0、4.2，選擇會保存於專案及本機草稿。
舊專案未指定版本時，沿用 4.0.56。改輸出版本會重新產生對應 JSON，不改粒子參數或軌跡。
3.8 使用 color 與 rotate.angle；4.0／4.2 使用 rgba 與 rotate.value；不是單純改版本標籤。
3.8 大角度旋轉會補入必要關鍵幀，避免 runtime 的最短角度插值省略整圈旋轉。
「掛接骨架」啟用時，選擇器顯示「跟隨骨架」並鎖定原骨架的完整版本；移除或停用掛接後恢復獨立輸出版本。
追加只把新粒子輸出為原骨架的版本，不會把原角色升級或降級；要轉換原角色版本，請在官方 Spine 編輯器另行處理。
官方 runtime 不接受 3.8.75 資料，該版本需在 3.8.99 重新匯出後使用。

編輯效果
保留圖片原檔名（v1.22）
1. 單張貼圖與連續圖輸出均保留合法 PNG 原檔名，包含中文、空白及 .PNG 副檔名的大小寫。
   例如「金光 粒子 01.PNG」會保留這個檔名，不再改成 emitter_發射器ID.png。
2. 複製發射器或載入不同的同名圖片時，會以子資料夾區隔，保留每張圖片的檔名與內容。
   大小寫不同或同一組連續圖內的重複檔名也會分開保存，避免在 Windows 解壓縮時互相覆蓋。
   沒有自訂貼圖時，內建柔光仍使用 particle.png。
3. JPEG／WebP 在載入時已轉為 PNG，輸出會保留主檔名並改用 .png 副檔名，避免檔案格式與名稱不符。
   不適用於檔名的特殊字元會必要修正；專案內仍保留原本的素材名稱，不修改原始磁碟檔案。
4. Spine 圖片路徑會同步指向輸出的實際檔案；請保留 images/ 或 new_images/ 下的完整子目錄。
   重新烘焙後再輸出，即可套用這次命名修正；舊下載包的檔案不會自動改名。
5. 新版「效果更新記錄.json」保存每個發射器的圖片路徑，仍可讀取舊版記錄及追加清單。
   後續更新效果時請使用對應的記錄，JSON 與圖片仍需來自同一次輸出。

發射器獨立種子與角度參考（v1.21）
1. 「發射 → 隨機變化」可選「跟隨專案 · 自動分組」或「自訂此發射器」。
   跟隨專案沿用上方「專案種子」，各發射器會自動分組，保留舊版結果。
   自訂種子為 0–4294967295 的整數，支援直接輸入和左右拖曳；0 是有效種子。
2. 相同獨立種子搭配相同參數，可重現相同粒子變化；複製發射器會保留這個種子。
   複製後按「換一組」或改種子數值，只改目前這一層，方便疊出不同粒子分布。
   跟隨專案的發射器也可直接按「換一組」，立即轉為獨立設定。回到跟隨專案可恢復原有分流方式。
3. 獨立種子不受上方專案種子或發射器名稱影響，會保存於專案、烘焙快照、自動草稿與我的效果庫。
   套用效果庫仍保留目前發射器的位置、名稱、啟用狀態與骨骼掛接；種子可隨效果一同重用。
   種子只改變已有的隨機項目，例如散射、出生位置、生命／速度／尺寸隨機；全部固定時，改種子可能看不出差異。
4. 選取發射器時，畫布顯示角度參考。圓環的圓弧範圍與粒子射出方向使用不同顏色。
   中心箭頭表示方向，兩側參考線表示角度邊界；縮小為 120° 時，可直接看出該範圍朝向哪邊。
   圓形發射器調整方向角度或散射角時也會顯示參考，範圍與角度調整即時更新。
   掛接預覽跟隨原父骨骼變形；角度文字表示發射器的局部設定。沿路徑移動時，由路徑決定方向。
5. 種子修改可復原／重做，修改後請重新烘焙再輸出。角度參考僅供預覽，不會增加 Spine 圖片或關鍵幀。
   examples/seed-layers.particle.json 展示三層相同參數、不同種子的效果，另附三版本 Spine ZIP。

粒子連續圖與播放 FPS（v1.20）
1. 到「外觀 → 粒子貼圖」按「載入連續圖」，一次選取多張圖片；依檔名數字排列，如 frame1、frame2、frame10。
   建議使用透明 PNG 並保持相同畫布尺寸與中心位置。圖片會內嵌於專案，不需另外設定外部路徑。
2. 「連續圖 FPS」可設定 1–120 的整數，支援左右拖曳數值；每輪時間為張數 ÷ FPS。
   這是圖片播放速度，與上方烘焙 FPS 分開。每顆粒子從自己的出生時間開始，不是所有粒子一起切圖。
3. 「循環播放」播完回第一張；「播放一次，停末張」播完保留末張，直到粒子生命結束。
   若生命長度短於連續圖一輪，粒子會在播完前消失。需要完整表演時請同時調整生命長度。
4. 載入連續圖不改原配色、透明度、尺寸、速度與路徑。保留圖片原色可套用「純白原色」配色。
   各張圖片共用像素縮放基準，不會因每張尺寸不同而自動放大到同一尺寸；圖片中心對齊粒子中心。
5. 「貼圖模式」可切換單張／連續圖，保留另一模式的素材。載入新單張圖片會切至單張；重新載入連續圖會切回連續圖。
   「重設」清除這個發射器的單張與連續圖素材，返回內建柔光；可一步復原。整批載入失敗時保留原素材。
6. 最多 120 張，每張轉換後的 PNG 不超過 4 MiB／2048 像素；專案所有內嵌素材合計不超過 16 MiB。
   連續圖、FPS 與模式會保存於粒子專案、草稿及我的效果庫，複製發射器也會保留。
7. 支援即時、烘焙與原骨骼掛接預覽，沿用 In／Loop／Out 的粒子時計與接續。
   Spine 3.8／4.0／4.2 使用多個圖片附件與 attachment 切換關鍵幀，會按連續圖 FPS 補入切換時間。
   修改後請重新烘焙並輸出，JSON 要搭配同次輸出的全部圖片；序列不需要遊戲端額外計算。
   範例：examples/sequence-particles.particle.json，以及三版本 sequence-particles_spine*.zip。

少量節點與貝茲移動路徑（v1.19）
1. 「運動 → 編輯路徑與控制點」的新預設使用真正的三次貝茲曲線：
   圓形／橢圓 4 點、8 字形 8 點、S 形 5 點、兩圈螺旋 9 點；直線仍為 2 點，矩形仍為 4 點。
2. 拖曳節點調整位置，藍色菱形控制柄調整弧度；中間節點預設鏡射平衡兩側，Ctrl 拖曳只改一側。
   「此節點的曲線」切換相鄰兩段的直線／貝茲；兩側不同時會顯示對應狀態。
   用「選取節點」可分別選取 8 字形中央重合的節點。端點只有實際存在的單側可調整。
3. 雙擊曲線或按「新增點」插入節點，貝茲分割保留原形狀；至少 2 點、最多 48 點。
   寬高同時縮放節點與控制柄。底圖、PNG 物件和掛接骨架維持相同座標，可直接對照定位。
   選取、平移、縮放只改編輯視角；按「套用路徑」才保存，取消或回到開啟時還原草稿。
4. 舊路徑開啟時保留原點數、平滑與形狀。可按「精簡為貝茲」轉換目前實際路徑，檢查後再套用。
   精簡以 0.75 個局部像素為幾何容差，點數依形狀而定，不一定等於新預設；無法在 48 點內完成時不改原路徑。
   折線仍可使用「折線平滑」，已使用貝茲的路徑改由控制柄調整弧度。
5. 控制柄會保存在粒子專案、自動草稿與我的效果庫；沿用骨骼掛接、速度曲線及 In／Loop／Out。
   編輯節點的數量與 Spine 關鍵幀數不同，輸出會補入必要曲線取樣。修改後請更新烘焙再輸出。
   examples/bezier-paths.particle.json 提供四種曲線示範，另附三版本輸出 ZIP。

操作整理、可視時間軸與我的效果庫（v1.18）
1. 外觀面板區分「配色預設」（整組顏色）與「此節點的顏色」（目前選取的一顆節點）。
   透明度預設與顏色漸層放在同區，透明度進階曲線收在「透明度進階曲線 · 貝茲」。
   展開後與上方透明度節點共用設定，並不是第二套透明度；展開或收起不會改動效果。
2. 可視時間軸顯示 IN／LOOP／OUT 的粒子長度，點一下可切換段落。
   掛接預覽顯示整段掛接動畫及粒子的開始／結束區間；IN 的末態保留區間以斜紋顯示。
   拖曳時間軸可定位並暫停；方向鍵逐格，Home／End 到精確起點與終點。這些操作只改預覽時間。
3. 左側「我的效果庫」可儲存目前發射器，包括配色、曲線、PNG、輪廓與路徑。
   選取儲存的效果後按「套用至目前發射器」，保留目前名稱、位置、啟用狀態與掛接骨骼。
   其他發射器、亂數種子、動畫段落與原骨架不受影響。套用後可一步復原，修改後請重新烘焙。
   刪除效果庫項目不會刪除專案中的效果；可按「復原刪除」取回。
4. 效果庫保存於目前瀏覽器，與粒子專案分開。請用「匯出效果庫」保存 .fx-library.json 備份；
   更換版本、資料夾、瀏覽器或電腦時，先匯出，再於新環境匯入。重複匯入會略過相同內容。
   工具包提供 examples/常用效果.fx-library.json，包含 6 組可編輯效果，可匯入直接試用。

顏色與生命曲線預設（v1.17）
1. 「外觀 → 生命期間的顏色」新增 7 組配色：金色光芒、火焰暖光、冰藍閃光、翡翠綠光、紫色魔法、彩虹流光、純白原色。
   下拉選擇先顯示配色小圖，按「套用」才修改目前發射器的顏色節點；原透明度與其他設定保留。
2. 透明度、尺寸、速度曲線各提供 6 組預設，包括淡入淡出、短促閃光、呼吸縮放、彈出回穩、逐漸加速與緩速煞停。
   每條曲線可分別套用，搭配小圖及效果說明選擇。套用後仍可拖曳節點與平衡貝茲控制柄微調。
   速度預設位於「運動」，套用後會啟用速度曲線；原本的移動節奏仍保留，可取消勾選恢復使用。
   生命期間走完整條路徑時，速度曲線調整前進節奏，仍走完整條路徑。
3. 每次套用可一步復原與重做，不會修改其他發射器。選擇預覽不影響專案或烘焙，套用後請重新烘焙再輸出。
   預設以實際顏色與控制點保存，舊專案照原有設定開啟；可在 examples/lifetime-presets.particle.json 查看組合示範。

效果更新與烘焙檢查（v1.16）
1. 工具列「烘焙檢查」提供精細、標準、精簡三種品質；切換後請重新烘焙。
   品質調整曲線精簡與補採樣容許誤差，不改變 FPS、亂數種子或粒子生命週期。
   面板先顯示骨骼、插槽和補採樣前估算；「試烘焙並檢查」顯示實際 KEY 數、減少比例和粒子 JSON 大小。
   精簡優先減少 KEY，實際結果依效果而定。數據不是裝置效能測試，JSON 大小不包含 PNG、圖集及原角色。
2. 追加包包含「效果更新記錄.json」，請跟原粒子編輯專案一起保留。
   在 Spine 修改骨架後：先開啟自己的粒子編輯專案，再到「掛接設定」載入修改後的骨架 JSON。
   展開「更新已追加的粒子效果」，載入對應記錄，預覽與輸出會替換原來這組粒子。
   也支援舊版的「追加清單.json」；舊記錄會保留可能原本存在的空動畫容器。
   「追加新效果」會保留舊效果，另外加一組；「更新此效果」使用原群組名稱。
3. 更新會檢查記錄中的骨骼、插槽、附件與動畫軌。若外部骨骼、約束或網格依賴這組粒子，會說明衝突並保留現況。
   輸出為新的 JSON 與 ZIP，請保留原 Spine 工程；new_images 裡的新圖片需覆蓋原 Images 的同名效果資料夾。
   JSON 和圖片要使用同一次輸出。舊素材檔不會自動從磁碟刪除。

復原、畫布選骨骼與各發射器圖層（v1.15）
工具列的「復原／重做」與 Ctrl＋Z／Ctrl＋Y／Ctrl＋Shift＋Z，可還原已完成的參數、曲線、路徑套用、增刪發射器、圖片與掛接設定；一次拖曳算一步。文字欄位內保留瀏覽器原生文字復原，離開欄位後可用全工具復原。
播放、拖時間軸、縮放、平移視角及單純選取發射器不新增歷史。開啟另一個專案會清空上一個專案的歷史；歷史只在本次開啟期間使用，自動草稿與儲存專案仍保留。
復原／重做後回到即時預覽，請重新更新烘焙再輸出；不會把先前的烘焙當成目前參數輸出。路徑視窗內仍以「取消／回到開啟時」還原未套用草稿。
掛接預覽按「畫布選骨骼」，滑過骨骼可看名稱與高亮，點一下掛接目前發射器；也可從「各發射器掛接與圖層」指定要在畫布挑選的發射器。選骨骼時動畫暫停，完成或按 Esc 取消後恢復原播放狀態。
「保持紅點位置」預設開啟：換骨骼時換算局部 X/Y，維持紅點當下的畫面位置；輪廓及粒子的旋轉、縮放仍跟隨新骨骼。關閉時保留原局部 X/Y。骨骼縮放為零無法保位，請改選骨骼或換動畫時間。
掛接設定內展開「各發射器掛接與圖層」，每個發射器可選「沿用共用圖層／最前方／最後方／指定插槽之後」。可將底部光暈放符號後、亮點放前；會跟隨原動畫的插槽順序變動與裁切範圍，三段動畫共用同一組粒子骨骼。

沿物件外型移動（v1.13）
「運動 → 沿路徑移動 → 沿物件外型移動」，或路徑編輯器的「預設路徑 → 沿物件外型 · PNG 輪廓」，可將已掃描的 PNG 邊界轉為封閉移動路徑。
已有參考物件時直接沿用目前物件位置及寬高；沒有物件時在同一視窗按「載入物件 PNG」。新 PNG 先以原像素大小顯示，超過 2000 像素時等比縮小至欄位範圍；保持物件與路徑對齊。
預設選最大外輪廓；多個獨立物件或內孔可在「移動輪廓」選取。一條路徑一次沿一個封閉輪廓，不會用直線把不同區塊串起來；要同時繞多個區塊，可複製發射器後各選一條輪廓。
輪廓轉為最多 48 個可編輯控制點，預設保留轉角、不疊加發射範圍與外力。可對照物件拖點、反向、調整平滑、路徑寬高與速度曲線；複雜細節會簡化，可手動調整控制點。
載入 PNG、選輪廓及拖點皆先修改視窗草稿，按「套用路徑」才保存並啟用；「取消」不改原專案，「回到開啟時」還原路徑與參考物件。物件輪廓不會改變原本發射形狀。
沿用骨骼掛接與 In／Loop／Out；輸出為 Spine 3.8／4.0／4.2 可用的粒子骨骼關鍵幀，參考物件不會成為粒子貼圖。範例：examples/outline-motion.particle.json 與三版本輸出 ZIP。

對照底圖編輯路徑（v1.12）
開啟「編輯移動路徑」時，預設顯示原背景、已載入的 PNG 參考物件；若使用掛接預覽，也會顯示原 Spine 骨架的素材及姿態。
背景採原始像素比例，物件以發射器位置及大小對齊；掛接時路徑與物件一起套用父骨骼矩陣，滑鼠拖曳仍保存骨骼局部 X/Y，不會把畫面座標直接寫成局部座標。
初始視角對焦目前路徑與選定物件，避免大背景把控制點縮得太小。滾輪以滑鼠位置縮放，拖曳空白處平移；按「對焦路徑」重新對焦。調整控制點與寬高時保持視角，避免底圖跳動。
「顯示底圖與參考物件」可暫時隱藏圖像，保留路徑、控制點及格線；不改變背景或參考圖的專案設定。此視角也不改主畫布的縮放與平移。
編輯期間動畫定格於開啟當下的時間，掛接骨骼不會繼續移動；關閉、取消或套用後，會恢復原本播放／暫停狀態。未能取得有效掛接姿態或父骨縮放為 0 時，會說明原因並禁止套用，避免座標錯位。
參考畫面只用於定位，不會加入 Spine 粒子貼圖或修改原骨架。完成後按「套用路徑」，再更新烘焙及輸出。

發射方向（v1.11）
在「發射 → 發射方向」可選「指定角度」、「隨機方向 · 360°」、「中心向外」、「輪廓向外 · 法線」。選取後即時更新預覽，選取的發射器會顯示少量初始方向箭頭。
「指定角度」沿用原方向角度及散射角；0° 向右、90° 向上。「隨機方向」讓每顆粒子的初始方向在完整 360° 中隨機選取，隨機種子固定時可重現。
「中心向外」以發射器紅點為中心，由粒子的出生位置往外射出，圓形或圓環可直接做放射效果；發射位置仍可選區域內或輪廓線。
「輪廓向外 · 法線」沿形狀邊界的垂直方向發射：正圓沿半徑向外、橢圓沿真實外法線、矩形四邊垂直向外；矩形區域內依距離最近一邊的實際像素距離選方向，同距離時優先左右邊。線形的法線為線段方向 +90°；點狀或退化形狀沿原指定角度作備用。
PNG 輪廓的法線朝透明側，包含凹形與多個獨立區塊；啟用內孔時朝孔內空白區發射。這與以整張圖中心放射不同，避免把內孔粒子射進實體區域。掛接骨骼時先以骨骼局部座標決定方向，再跟隨父骨骼變形。
向外模式的「方向散射」預設為 0°，直接精確向外；增加可加入角度偏移，360° 代表完整隨機。此欄與原指定角度的散射角獨立保存，切換模式保留原角度及數值。
原專案未指定方向方式時，沿用「指定角度」及原隨機結果。速度、風力、重力與生命曲線仍可繼續疊加；「貼圖朝向移動方向」可讓貼圖隨方向轉動。
使用沿路徑移動時，方向由路徑決定，方向選單與相關欄位暫停作用；停用路徑後恢復所選模式及原數值。四種方式都能烘焙至 Spine 3.8、4.0、4.2，以及 In／Loop／Out 與既有骨骼掛接動畫。

X／Y 分軸大小變形（v1.24）
「外觀 → 生命期間的曲線」新增「分別調整 X／Y」開關，預設關閉，維持一條尺寸曲線同時縮放寬與高。
首次開啟時，從原本的統一尺寸曲線複製成 X（寬度）與 Y（高度）兩組，再各自編輯；既有曲線形狀與貝茲控制柄都會保留。
兩軸各有預設、節點、倍率與線性／階梯／貝茲選項，可做橫向拉伸、縱向壓扁、回彈等效果；1 為原倍率，0 為該軸縮至零，最大 4 倍。
關閉開關時，恢復原本的統一尺寸曲線；已編輯的 X／Y 曲線會保留，下次開啟可繼續調整。
每個發射器各自保存開關與曲線，支援複製、復原／重做、儲存專案與我的效果庫。舊版專案不會自動切換為分軸。
預覽與 Spine 3.8／4.0／4.2 烘焙均使用同一組 X／Y 縮放，可搭配路徑轉向、骨骼掛接、連續圖與 In／Loop／Out。
示範：examples/size-axes.particle.json，貼圖已內嵌，可直接查看拉伸與壓扁效果。

沿路徑方向轉向（v1.23）
在「運動 → 沿路徑移動」啟用路徑後，可直接勾選「沿路徑方向轉向」，不必切到外觀頁；直線、貝茲、圓形、反向前進及 PNG 輪廓路徑皆可使用。
「轉向偏移」校正貼圖正面：原圖朝右時用 0°，原圖朝上時用 −90°；可直接輸入或左右拖曳，與「外觀 → 起始旋轉」同步。
方向開關與外觀頁共用同一設定。未勾選時維持起始旋轉與自轉；既有專案不會自動啟用或改動參數。
若原有旋轉速度或旋轉隨機不為 0，會繼續疊加自轉；按「停止額外自轉」一次歸零兩個值，可復原。勾選轉向本身不會清除自轉。
開放路徑到終點後維持終點朝向；封閉路徑跨圈保持連續旋轉。疊加外力時，朝向仍依原路徑，不改為外力偏移後的實際移動方向。
請用箭頭或長條等有方向的貼圖查看效果，圓形貼圖不易看出轉向。即時預覽與 Spine 3.8／4.0／4.2 的烘焙皆沿用同一設定。
示範：examples/path-facing.particle.json；已內嵌箭頭貼圖，可直接開啟並切換轉向開關比較。

沿路徑移動（v1.10）
在「運動」頁勾選「沿路徑移動」，或按「編輯路徑與控制點」設定後套用。
支援直線、矩形繞框、圓形／橢圓、S 形、8 字形、螺旋；可拖曳控制點、直接輸入 X/Y、雙擊新增、右鍵或 Delete 刪除。至少 2 點、最多 48 點。
v1.10.3 起，選取預設形狀就立即產生控制點，不需再按套用預設；寬高修改會直接縮放目前路徑。手動移動或增刪控制點後顯示「自訂／目前路徑」，不會在調整尺寸時重新生成模板。
重新開啟會保留已保存的路徑，選單依實際幾何顯示預設或自訂。上方「重設形狀」重新產生所選預設，下方「回到開啟時」恢復開啟當下的路徑；最後按「套用路徑」才會修改發射器，取消不變更原專案。
「封閉路徑」連接末點與起點；「反向前進」改變行進方向；折線平滑 0 保留轉角，1–3 逐步柔化（平滑會略微內縮輪廓，矩形精確繞框請使用 0）。貝茲路徑以控制柄調整。
「生命期間走完整條」以各粒子的實際生命長度控制總時間，速度欄暫停作用；速度曲線會正規化總距離並調整途中快慢，整條為 0 時停在起點。
「依像素速度前進」沿用速度／速度隨機與速度曲線；開放路徑到終點保持，封閉路徑可繞多圈。
預設貼合路徑，發射形狀散佈、發射方向與外力暫停作用，原欄位數值保留。勾「疊加發射範圍與外力」後，加上出生散佈與風力／重力；初速度不會額外偏離路徑。
「沿路徑方向轉向」在路徑模式使用路徑切線，與外觀頁的方向對齊共用設定；疊加外力後仍以路徑切線朝向，旋轉速度可另外疊加。
路徑以發射器紅點為原點，X 正值向右、Y 正值向上。拖紅點會整體移動路徑；掛接時控制點屬於選定父骨骼的局部座標，會隨原骨骼一起運動。
每個粒子依自己的出生／生命時計走路徑，可用發射時間排出光串；這是粒子自身沿路徑前進，並非發射器沿路徑移動後留下物理拖尾。
取消編輯不修改專案，停用路徑仍保留控制點。路徑已烘焙為骨骼位移／旋轉，可輸出 Spine 3.8、4.0、4.2 並追加至既有動畫，無須額外 Spine Path Constraint。
低 FPS 時會補入轉角及必要的曲線取樣，再縮減 KEY；極端速度、小路徑或大量粒子的匯出成本若超過 200 萬取樣會停止，請降低數量或速度。

掃描物件輪廓發射（v1.10）
在「發射 → 形狀」選「物件輪廓 · 掃描 PNG」，載入透明背景 PNG。支援 4 MiB／2048 像素以内的圖片。
依 Alpha 值掃描物件的實際像素邊界，保留凹形及多個獨立區塊；「也沿內孔發射」可包含中空物件的內側邊框。粒子依各邊框周長分配，並非依控制點數量分配。
透明度閾值範圍 1–255，預設 24；提高可排除透明暈邊，降低可納入較淡部分。修改後按「依新閾值重新掃描」。沒有透明背景的 PNG 會掃成整張圖的矩形外框。
圖片完整畫布中心對齊發射器紅點；寬度／高度調整輪廓顯示大小，透明留白也會保留。輪廓簡化後每個區塊最多 256 點、最多 32 個區塊、合計最多 2048 點；過多透明雜點會要求先清理圖片或提高閾值。
「畫布顯示參考物件」僅供編輯對照。圖片與輪廓會保存在 .particle.json，可重載及重新掃描；參考物件不會加入輸出的 Spine 粒子貼圖，請在原 Spine 工程保留原物件素材。
輪廓決定粒子出生位置，出生後仍依原速度／外力移動。若同時使用嚴格貼合路徑，請勾「疊加發射範圍與外力」或停用路徑，才能使用輪廓作為出生範圍。
目前掃描取透明度邊界，並非從不透明背景自動辨識物件；程序化光帶、閃電與逐幀貼圖效果未納入本次骨骼烘焙。

In / Loop / Out 三段動畫
按動畫設定列的「動畫段落」，勾選「啟用三段動畫」。In、Loop、Out 各有獨立的動畫名稱及長度，範圍 0.05–30 秒；長度欄位可左右拖曳。
In 以預熱循環畫面淡入，結尾對齊 Loop 起點；Loop 依發射器的數量、發射時間、生命曲線等設定反覆播放；Out 停止新生粒子，存活粒子繼續移動並淡出，最後完全隱藏。
若需要 Loop 整段持續有粒子，請將發射器的「發射時間」設為 Loop 長度，並調整粒子數與生命長度；短發射時間仍可用於每輪反覆出現的爆發效果。
三段共用同一套骨骼、插槽與圖片，不會產生三套重複粒子。背景參考圖仍不輸出。
按「更新三段烘焙」後，畫布上方可分別選 IN／LOOP／OUT 檢查；「串接試播」會先播 In，再反覆 Loop。
按「結束 Loop」，會等目前完整一輪結束再播放 Out，最後停止。單獨預覽 In 或 Out 時，只播放一次。
獨立輸出的骨架 JSON 內含三個動畫，套件「動畫段落.json」記錄各名稱、長度與循環設定。匯入 Spine 或遊戲後，請將 Loop 設為循環，In 與 Out 設為單次播放。
Out 只保證在 Loop 完整一輪的邊界銜接；遊戲任意時點立即切換 Out，需要安排到循環結束，或自行設定動畫混合。
保證銜接的是粒子的局部狀態。掛接原骨架時，原父骨骼在 In／Loop／Out 三個原動畫中的姿態也需連續。
勾選掛接後，「三段表演掛接」可為 In、Loop、Out 分別追加到原動畫或建立新動畫，In 與 Out 可各設定開始偏移時間。
Loop 固定從 0 秒開始；原 Loop 長度大於粒子 Loop 時會阻擋輸出，請加長粒子 Loop 或選擇新動畫。原 Loop 較短時，會保留原軌並延長動畫至粒子 Loop 長度。
原本的單段模式可繼續使用：取消「啟用三段動畫」即可，三段設定會保留。三段專案請用 v1.7 或更新版本開啟。
超短 Loop、很長 In 與大量粒子會增加取樣與 KEY；匯出前估算超過 200 萬取樣會先停止，請減少粒子、縮短 In 或延長 Loop。

單段與發射器編輯
1. 左側選擇效果類型，按「＋」新增發射器，可複製、刪除或調整圖層順序。
2. 右側「發射／外觀／運動」調整參數、貼圖與曲線；拖曳曲線控制點調整生命期間變化。
3. 點選紅色控制點選取發射器，直接拖曳調整位置，X／Y 欄位同步更新；拖曳空白區移動視角，滾輪縮放。
   選取紅點後可用方向鍵微調 1 px，Shift＋方向鍵移動 10 px；「置中發射器」設為 X=0、Y=0。
   停用發射器仍可調整控制點位置。控制點操作後需更新烘焙再輸出。
4. 使用播放、逐格與時間軸檢查效果。X 向右為正、Y 向上為正。
   外力「風向」：正值向右吹、負值向左吹；「重力」：正值向下、負值向上；0 表示無此外力。
   兩者以 px/秒² 表示，絕對值越大作用越強，皆可左右拖曳調值。
   舊專案的角度式風力會換算成等效的左右風向與上下重力，保留原本的軌跡。
5. 背景參考圖僅供畫布對照，不會作為 Spine 粒子輸出。
   v1.10.2 起，背景保留來源像素大小：2440×1440 背景與 270×240 物件使用相同座標比例。載入背景時會縮放整個視角來顯示背景，不改變粒子的尺寸或位置。
   大背景的保存預覽圖可能縮到 2048 像素，但顯示及編輯使用原始尺寸；原始寬高會保存於專案。視角可縮放至 5%，儲存再開啟也會保留。
   舊專案保留原背景與位置設定；按背景列「校正尺寸」可還原已保存圖片的像素比例。舊版未保存大背景的原始尺寸，請重新載入原背景圖，才能精準恢復。

拖曳數值欄位
滑鼠按住數值欄位中央後左右拖曳：向右增加、向左減少，不必按在小箭頭上。
Shift 為 10 倍速度；Alt 為慢 10 倍，可精細調整，數值仍遵守欄位步長及上下限。
普通點擊後可直接鍵入數字，右側原有小箭頭也能使用；短於 4 px 的位移不會調值。
拖曳途中按 Esc 可恢復原值。位置、角度、線長、生命、速度、動畫長度和種子等數值欄位皆可拖曳。
拖曳時預覽持續更新，放開滑鼠後會保存草稿。若已烘焙，修改後需重新更新烘焙再輸出。

新增形狀設定
形狀與發射位置分開設定：先選長方形、圓形或圓環，再用「發射位置」選「區域內」或「輪廓線上」。
「區域內」讓粒子從形狀的內部區域出生；「輪廓線上」只從邊界出生。長方形的四條邊依邊長分配粒子，不會只集中在角落；圓環輪廓會遵守設定的弧段範圍。
要做長方形外框粒子：選「長方形」→「輪廓線上」，調整寬／高，再按「更新烘焙」。若希望粒子留在框線上，將速度及速度隨機、重力、風向設為 0；若有速度或外力，粒子出生後仍會依原運動設定移動。
舊專案未指定發射位置時，長方形／圓形沿用區域內，圓環沿用輪廓線；保持原本的隨機種子、發射位置與軌跡。新發射位置選項會保存於專案與草稿，請使用 v1.9 或更新版本編輯。
線形：可設定「線長」（0–2000 px）與「線段方向」。線段以紅色控制點為中心，0° 水平、90° 垂直。
圓環：寬高控制圓／橢圓尺寸；「圓環範圍」360° 是完整圓環，120° 是指定弧段。
「弧段中心方向」0° 向右、90° 向上；例如中心 90°、範圍 120°，即朝上、左右各 60°。
區域的方向與粒子的「發射方向／散射角」可分開調整。
舊專案可以直接開啟；新增的線形與圓環弧段請使用 v1.1 或更新版本的工具編輯。

生命週期顏色與透明度
「外觀」中的漸層上排是透明度節點，下排是顏色節點；中間棋盤底顯示實際 RGBA 變化。
按「＋透明度／＋顏色」新增節點，點選節點後可左右拖曳生命位置，或在下方欄位輸入百分比、顏色或透明度。
每排最多 32 個節點；0% 與 100% 端點固定位置，中間節點可用垃圾桶或 Delete 刪除。
透明度節點與下方透明度曲線共用資料，任何一處修改都會同步；透明度 0 完全透明，1 完全不透明。
顏色在相鄰節點之間漸變，透明度可另外使用貝茲或階梯曲線。RGB 顏色與 Alpha 可設定不同數量、不同生命位置的節點。

貝茲與速度曲線
透明度、尺寸與速度曲線皆可選擇「線性／貝茲／階梯」。v1.14 起，中間節點選「貝茲」會同時啟用左右兩段，並顯示該節點自己的兩支藍色控制柄；端點只有一側可調整。線性／階梯仍設定該節點之後的區段，選最後端點時設定最後一段。
一般拖曳任一藍色菱形控制柄，另一側會以節點為中心鏡射連動，形成平衡貝茲；按住 Ctrl 拖曳可單獨調整一側，拖曳途中也能按下或放開 Ctrl 切換。
左右區段長短不同時仍依實際生命位置保持對稱；碰到相鄰控制柄或數值上下限時，共同縮短兩側，避免交叉或破壞平衡。既有曲線不會因開啟或點選節點而自動平衡。
金色圓點控制生命位置與數值。點擊曲線空白處新增節點，右鍵或 Delete 刪除中間節點。
下方生命位置與倍率欄位也支援左右拖曳、Shift 加速、Alt 微調，以及拖曳途中 Esc 恢復。
「運動」頁勾選「啟用速度曲線」，或直接編輯速度圖表，將使用自訂速度倍率曲線；1 為初始速度、0 停止、2 為兩倍，範圍 0–4。
速度會沿生命期間累積成實際位移；重力及風力仍依時間作用。啟用速度曲線會覆蓋「移動節奏」，取消勾選或重設速度曲線可回到原設定。
取消勾選會保留自訂曲線，儲存並重開專案後仍可重新啟用；「重設」才會清除自訂速度曲線。
曲線控制柄與多段顏色會保存於 .particle.json；Spine 輸出採取樣烘焙的關鍵幀，以兼容 3.8、4.0、4.2，請修改後更新烘焙。
舊版專案會保留原本的起始／結束色及移動節奏；使用新增功能的專案請以 v1.3 或更新版本開啟。

保留編輯進度
工具會嘗試在目前瀏覽器保存並恢復本機草稿；瀏覽器設定、清除資料或更換檔案位置，可能使草稿不可用。
請另外按「儲存專案」下載 .particle.json 檔。它包含參數、貼圖、背景與已烘焙快照，可用「開啟」接續編輯。
建議重要版本另存不同檔名。本機草稿不等於另存專案檔。
快捷鍵：Ctrl+S 儲存專案；未輸入參數且未聚焦紅點時，空白鍵播放／暫停，左右方向鍵逐格檢查。其他快捷鍵見上方 v1.25 說明。

烘焙與輸出
「即時預覽」反映目前參數；「更新烘焙」產生固定幀率的骨骼與關鍵幀，並切到烘焙結果。
修改粒子參數後會顯示「輸出時自動烘焙」；按「輸出 Spine」會先重新烘焙再下載，不會交付舊效果。
按「輸出 Spine」下載 ZIP，解壓縮後保留以下內容：
  專案名稱.json            所選版本的 Spine 動畫資料
  images/                  粒子 PNG 素材
  專案名稱.particle.json   本工具的編輯專案
  匯入說明.txt              該次輸出的設定與匯入指引

匯入對應版本 Spine
1. 解壓縮 ZIP；保留 Spine JSON 與 images 資料夾的相對位置。
2. 在 Spine 使用「檔案 → 匯入資料」（File → Import Data），選擇專案名稱.json。
3. 確認 Images 路徑指向同層的 images/ 資料夾，播放 effect 動畫；循環效果需開啟循環播放。
4. 存成新的 .spine 專案。需要圖集時，在 Spine 匯出流程建立 atlas。
5. 若要整合到既有角色／特效，先保存新 .spine 專案，再使用 Import Project 匯入並檢查骨骼、動畫與素材名稱。

追加至既有 Spine 骨架
1. 畫布上方按「掛接骨架」，載入原工程的 Spine 3.8、4.0 或 4.2 JSON。原生 .spine 請先用本包的「啟動Spine工程轉換.cmd」轉成 JSON，或在對應版本 Spine 匯出 JSON，勾選 Nonessential。
2. 選「預設父骨骼」。可搜尋骨骼名稱，也可展開「各發射器分別掛接」，把不同發射器指定到不同骨骼。
3. 選「追加至原動畫」或「新增動畫」，設定開始時間。原表演保留，新增粒子只播放目前烘焙長度的一段，結束後隱藏。
4. 設定最前方、最後方或指定插槽之後。父骨骼控制移動；插槽控制前後圖層，兩者分開設定。
5. 更新粒子烘焙，再按「輸出追加包」。載入且啟用掛接時，上方輸出按鈕也會改成追加包；取消「啟用追加輸出」可繼續輸出獨立特效。
6. 將追加包 new_images/ 裡的群組資料夾複製進原工程的 Images 根目錄。它使用唯一的名稱，避免新增圖片與原素材相撞。原角色圖片、atlas、音效請繼續保留。
7. 將合併 JSON 放在原骨架 JSON 的同層，維持原 Images 相對路徑。用 Spine Import Data 匯入，或用轉換工具產生新的 .spine，再播放目標動畫檢查，另存新版本。

掛接座標與保存
X/Y 為父骨骼的局部座標，粒子整個群組會隨父骨骼平移、旋轉、縮放；不是發射後留在世界座標的粒子。
啟用掛接後，畫布可切換「掛接預覽」或「粒子單獨」。掛接預覽使用對應版本官方 Spine runtime，粒子會跟隨原動畫的骨骼，包含 IK、transform/path 約束與不同骨骼繼承模式。
掛接預覽的時間軸是完整目標動畫的時間：例如原動畫 4 秒、粒子開始 1.5 秒、粒子長度 1.2 秒，畫布會播放 0–4 秒，粒子只在 1.5–2.7 秒出現；原骨骼從 0 秒持續表演。
三段掛接時，各段也使用對應目標動畫的完整時間。In 在開始偏移前隱藏，粒子 In 結束後保留尾端姿態直到原 In 完成；Out 的粒子退場後隱藏，原 Out 剩餘時間仍會播放。串接試播會依這個完整時間切換各段。
按「跳到粒子開始」可直接檢查開始位置；「對焦掛接點」與對話框「定位掛接骨骼」會將目前選取發射器的父骨骼移到畫布中心。「骨架」開關控制骨骼線，Skin 選單可切換原皮膚。
紅色發射器控制點會跟隨父骨骼。拖曳時工具將畫布上的移動換算回父骨骼局部 X/Y，包含旋轉、縮放與鏡像；拖曳時暫停表演，放開後需重新烘焙再輸出。
若父骨骼縮放為 0 或無法反算局部位置，控制點會提示無法拖曳；請調整時間或用 X/Y 欄位修改。
新增動畫沒有原角色骨骼軌時，掛接預覽使用原骨架的 setup pose；選追加原動畫才能預覽該動畫的骨骼表演。
原 JSON 的骨骼、插槽、皮膚、約束、事件、動畫軌與圖片路徑保留；原 drawOrder 軌會調整偏移索引，以維持原角色各圖層的相對順序。
新增群組若重名會自動加後綴。新動畫名稱若與原動畫重名，介面會阻擋輸出，避免將新動畫誤追加到既有動畫。
「儲存專案」與本機草稿包含原骨架 JSON、掛接設定及已載入的角色預覽素材，下次開啟不必重新選父骨骼或素材。
JSON 往返只能保留已匯出的資料，未匯出的編輯器資料無法由本工具還原；請一直保留原 .spine 工程。

掛接預覽素材
「掛接骨架」對話框的「原骨架預覽素材」可載入多張 PNG、JPEG 或 WebP；素材會轉成 PNG 供本機預覽。
原始圖片含子目錄時，請按「選擇 Images 資料夾」，選原工程 Images 根資料夾。工具只移除所選根資料夾名稱，保留 body/head.png 等相對路徑，以對應原骨架附件。
若原工程使用 atlas，按「載入 Atlas 圖集」選 .atlas 純文字檔，再載入對應的 PNG 頁面；多頁圖集需要載入所有頁面。
已存在的圖片相對路徑不會被覆蓋；如需更換素材，先按「清除預覽素材」，再載入正確的資料夾或圖集。
未載入或缺少角色圖片時，骨架與粒子仍可預覽，狀態列會列出缺圖；缺圖不代表角色沒有該附件，也不影響原骨骼跟隨。
每張素材檔案及轉換後 PNG 上限 4 MiB；預覽圖片最多 2048 像素，過大的圖片會依比例縮小。內嵌預覽素材合計上限 16 MiB；Atlas 純文字上限 256 KiB。
原角色素材只供預覽及編輯專案保存，不會重複加入 new_images/；追加輸出仍沿用原素材路徑，原工程圖片、atlas 與音效需自行保留。
畫布支援 region、加權 mesh、deform、clipping、drawOrder 與常見混合模式。正式交付請繼續在 Spine 及目標遊戲檢查最終外觀。
Spine 4.2 的圖片 Sequence 附件會依原動畫選擇目前影格；請載入完整的影格圖片或對應圖集。v1.9 同時包含 Sequence 讀取修正，缺少圖片時仍可檢查骨架與粒子的位置。
Spine 4.2 的 Physics 物理約束目前不支援掛接預覽。含 Physics 的骨架會顯示明確提示，請切回「粒子單獨」；追加輸出仍完整保留原 Physics 資料。

Spine 工程轉換工具
雙擊「啟動Spine工程轉換.cmd」，選 .spine 會輸出 _particleSource.json；選合併 JSON 會匯入成新的 _particles.spine。
需要本機已安裝 Spine.com，並已在官方 Spine 啟動過要使用的版本，使該版本存在本機快取。轉換工具不安裝或下載版本。
原生 .spine → JSON 時，選擇原工程所用的 3.8／4.0／4.2 版本；JSON → .spine 自動使用 JSON 的完整版本號，避免誤升級或降級。
命令列原生工程匯出可指定 -SpineVersion 3.8.99、4.0.56 或 4.2.43；省略時沿用 4.0.56。
預設使用 C:\Program Files\Spine\Spine.com。其他位置可在腳本命令列傳入 -SpinePath。
原檔與既有輸出不覆蓋；預設遇重名加後綴。轉換只支援單一骨架，多骨架工程請在 Spine 中選擇目標骨架匯出。
產生的圖片路徑沿用原設定；若搬到不同資料夾，請在 Spine 調整 Images 路徑。GUI 選檔流程由使用者操作；CLI 往返已在 3.8.99、4.0.56、4.2.43 實測。

使用範圍
這是獨立開發的粒子編輯工具，透過烘焙產生可編輯的骨骼動畫。
大量粒子或長壽命會增加骨骼與關鍵幀數；請依交付規格控制粒子量。
目前遊戲 runtime、PMA（預乘 Alpha）、圖集設定與動畫混合／中斷尚未完整驗證，正式交付前需在目標遊戲測試。
整合到既有 Spine 工程時，請使用匯入流程並檢查素材路徑與圖層順序。
Spine 動畫 JSON 與其他工具的參數檔不能直接當作本工具的 .particle.json 專案開啟。
本機骨架預覽內嵌 Esoteric Software 的官方 Spine Runtimes，授權與版權聲明見 assets/spine-runtime-licenses.txt；同一聲明亦保留於離線 HTML。

examples/object-outline.particle.json 展示自製透明五角星與內孔發射，對應 object-outline_spine3.8.zip、object-outline_spine4.0.zip、object-outline_spine4.2.zip。掃描測試 PNG 在 examples/images/outline-object.png。
examples/border-emission.particle.json 展示形狀與發射位置分開設定，可開啟後切換「區域內／輪廓線上」比較出生位置。
examples/attached-preview.particle.json 包含自製的動畫骨架、IK、mesh 與內嵌圖片，粒子掛在 hand、lower 與 noScale 骨骼下；原 main 動畫 4 秒、粒子開始 1.5 秒，開啟時停在 1.8 秒，可直接拖曳紅點或切回 0 秒檢查開始偏移。
examples/attached-preview-flow.particle.json 是同一測試骨架的三段掛接範例，包含原 existingIn／existingLoop／existingOut 動畫與獨立的 In／Out 偏移；可使用串接試播檢查完整動畫時序。
examples/in-loop-out.particle.json 展示 FX_In 0.6 秒、FX_Loop 1.2 秒與 FX_Out 0.7 秒；三段共享 64 個粒子骨骼。
examples/in-loop-out_spine3.8.zip、in-loop-out_spine4.0.zip、in-loop-out_spine4.2.zip 為同一示範的三版本實際工具輸出套件。
examples/golden-dust.particle.json 可用本工具「開啟」接續編輯。
examples/golden-dust_spine4.0.zip 是可搬移的 JSON + images 套件，已通過實際 Spine 4.0.56 匯入與素材打包。
examples/line-and-arc.particle.json 展示 300 px／30° 線形與朝上的 120° 橢圓弧段，可點選兩個紅點切換、拖曳及修改數值。
examples/line-and-arc_spine4.0.zip 是該示範的 Spine JSON + images 套件。
examples/lifetime-gradient.particle.json 展示多段顏色、獨立透明度與貝茲速度／尺寸曲線。
examples/lifetime-gradient_spine4.0.zip 是通過實際 Spine 4.0.56 匯入驗證的對應套件。
examples/lifetime-gradient_spine3.8.zip 與 examples/lifetime-gradient_spine4.2.zip 是實際工具輸出的對應版本套件，已通過各版本官方 runtime 的位置、旋轉、透明度與顏色比對。
examples/attach-to-existing.particle.json 包含原骨架、粒子與掛接設定，展示把粒子掛在 hand 下、0.4秒追加到 main 動畫、放在 handSlot 之後。
examples/attach-to-existing_spine4.0.zip 包含示範原骨架、合併結果與完整示範素材，可直接依說明匯入Spine4.0.56；示範的原骨架JSON為examples/attach-to-existing.json。
原始碼工作區另附 examples/golden-dust.spine，可在目前資料夾直接開啟（未放入離線版 ZIP）。若要搬移此工程，先在 Spine Editor 將 Images 的 Path 設成 ./images/ 再存檔；Spine 4.0 CLI 建立工程的素材路徑有已知限制。
