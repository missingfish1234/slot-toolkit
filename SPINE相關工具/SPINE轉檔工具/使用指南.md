# SPINE 轉檔工具｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

透過本機 Spine CLI，批次處理 .spine 專案的 3.8／4.0 升級、同版輸出或降級；不是只改副檔名。

## 環境與啟動

Windows、Python 3.10+／tkinter 及合法可用的 Spine.exe。執行 `spine_converter_gui.py`；輸入為製作專案資料夾與圖片資源，不是任意 JSON 轉換器。

## 操作步驟

1. 選模式：3.8 → 4.0、3.8 → 3.8 或 4.0 → 3.8。填入本機可用的精確版號及 Spine 執行檔。
2. 指定互不包含的來源／輸出資料夾；不要將輸出設在來源內，也不要設相同位置。
3. 設定遊戲包與圖片打包倍率，決定複製原圖及保留製作檔。第一次用一份專案測試。
4. 按「開始執行管線」，閱讀逐項日誌；需要中止按「停止」，已完成的項目會保留。

## 輸出與保存

依選項輸出遊戲用 SKEL／atlas／貼圖及目標版本 .spine。既有成果備份保存在輸出下 `.spine_backups`；每次僅發布該任務產物。

## 常見問題與限制

- 降級經 JSON 處理，可能遺失路徑／變形等資料，不應視為無損；以目標版本實際播放驗收。
- CLI 執行有五分鐘逾時；失敗時查看日誌、版本及授權，不要刪除來源重試。
- 自動複製原圖會尋找 images／image／textures／texture／tex；特殊路徑需自行確認。

## 驗收檢查

以目標 Spine 版本開啟製作檔，並在目標引擎播放所有重要動作，檢查圖片、縮放、約束及變形。
