# SPINE轉檔工具

版本 1.0.1（2026-09-05）

使用本機 Spine CLI 批次升級／降級／同版本轉出遊戲資源。

Windows 與 Python 3.10+、tkinter、本機合法 Spine.exe。執行 spine_converter_gui.py。輸入 .spine 專案資料夾；輸出分開且不互相包含的資料夾。每次僅合併本次產物，其他檔案保留；舊版完整保存在輸出/.spine_backups，可手動還原。取消只影響目前工作，已成功的前幾份仍保留。降級限制仍依 Spine 官方，原圖使用 images/image/textures/texture/tex。

本次更新：隔離本次產物、安全發佈並保留舊成果；加入取消／五分鐘逾時與主執行緒 UI 更新。

驗證範圍：原始碼／隔離回歸與引擎編譯結果見本次更新驗證報告；畫面效果與實際素材需按專案環境驗收。舊版說明保留供操作參考，以本文件的新參數與限制為準。
