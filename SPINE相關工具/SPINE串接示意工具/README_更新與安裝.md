# SPINE串接示意工具

版本 1.1.0 / V124（2026-10-12）

Spine 3.8／4.0／4.1 動畫串接、時間軸編排與示意影片匯出。

用 Chrome／Edge 開啟 SpinePlayTest.html，必須保留 vendor 與 scripts 資料夾。輸入匹配版本的 JSON／SKEL、Atlas、PNG；輸出專案 JSON 或瀏覽器支援的影片。新舊專案 JSON 相容；Spine 版本仍須手動與來源一致。

本次更新：新增每個 SPINE／圖片的初始顯示與時間軸開關；將物件、動作、目標軌與插入方式集中到固定操作區。切换物件清除舊片段選取，保留各物件的動畫選擇；複製時包含所有動畫次軌與開關。匯出區可收合，所選片段屬性優先顯示。

開關用法：取消「初始開啟」，將播放頭移到 1 秒，按「此時開啟」；移到 3 秒，按「此時關閉」。該物件在 1 秒起顯示，3 秒起隱藏。點選開關事件可修改時間／狀態，也可以直接拖曳事件；同一時間再設開關會覆寫。開關控制顯示，不卸載素材或改變動畫軌。沒有開關資料的舊專案維持全程顯示。

新增動畫可選「播放頭位置（後段順延）」或「接在此軌最後」。播放頭插入會完整保留原片段，將碰到的片段及後續片段向後排；其他軌與開關時間不會自動移動。Ctrl+Z 可復原這次編排。

開關與初始顯示會保存於專案、自動保存及複製，並包含於程式 JSON、Cocos .anim 與參考腳本。使用 Cocos .anim 時，目標節點須掛上本資料夾的新版 SpineTimelineHook.ts；它只開關 Skeleton／Sprite 元件，讓 Animation 仍可呼叫後續開啟事件。原生 .anim 的 Spine 動作仍以 T0 為主，次軌可從 JSON 或參考腳本接入。Cocos 編輯器的實際播放仍需在專案內驗收。

素材超過瀏覽器自動保存容量時，固定操作區會顯示提示，請使用右上角 💾 手動保存專案 JSON。

驗證：14 項編排回歸、素材回歸，以及含 38 組原生匯出相容性比對的開關匯出回歸通過；瀏覽器載入現有 Spine 3.8 五角色專案，確認開關編輯、時間跳轉及角色動作記憶。未在 Cocos 編輯器實機播放驗收。舊版說明保留供操作參考，以本文件的新參數與限制為準。
