# SPINE串接示意工具

版本 1.0.1（2026-09-05）

Spine 3.8／4.0／4.1 動畫串接、時間軸編排與示意影片匯出。

用 Chrome／Edge 開啟 SpinePlayTest.html，必須保留 vendor 資料夾。輸入匹配版本的 JSON／SKEL、Atlas、PNG；輸出專案 JSON 或瀏覽器支援的影片。新舊專案 JSON 相容；Spine 版本仍須手動與來源一致。

本次更新：修正 Atlas 存讀／複製、缺圖驗證與失敗保留原專案；內附固定版本離線相依檔。

驗證範圍：原始碼／隔離回歸與引擎編譯結果見本次更新驗證報告；畫面效果與實際素材需按專案環境驗收。舊版說明保留供操作參考，以本文件的新參數與限制為準。
