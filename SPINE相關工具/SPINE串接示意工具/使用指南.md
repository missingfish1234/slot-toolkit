# SPINE 串接示意工具｜使用指南

依 V124 現有程式與說明整理：2026-10-12。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

將多個 Spine 動作、圖片及位移串成時間軸，製作演出示意影片與程式參考資料；不是直接修改原 .spine 製作檔。

## 環境與啟動

Chrome／Edge 開啟 `SpinePlayTest.html`，完整保留 `vendor` 與 `scripts`。介面提供 Spine 3.8／4.0／4.1，先選與來源一致版本，再準備 JSON／SKEL、atlas 與全部 PNG。

## 操作步驟

1. 選版本，使用「匯入 Spine 角色」載入完整素材組；需要圖片物件／背景時另外匯入。
2. 在右側固定操作區選物件、動作、目標動畫軌。選「播放頭位置」插入並讓後段順延，或選「接在此軌最後」。選取片段可調開始時間、長度、Loop、Mix 與變形屬性。
3. 設定「初始開啟」，將播放頭移到指定時間，按「此時開啟」或「此時關閉」。每個物件有自己的開關軌，狀態維持到下一個事件；倒拉或跳時間仍按當時狀態顯示。點事件可改時間與狀態，同時間操作會覆寫。
4. 在不同時間點記錄位移等狀態，並播放／停止檢查。切換物件會清除舊片段選取，記住各物件的動作與動畫軌；複製可包含所有次軌與開關。Ctrl+Z 可復原編排或開關變更。
5. 右上角 💾 保存可再編輯專案；下方展開「匯出影片 / Cocos / JSON」可交付影片或接入資料。

## 輸出與保存

專案 JSON、演出參考 JSON、瀏覽器支援的 MP4／WebM，或 Cocos `.anim` 與對應腳本。用途不同，交付時說明哪份是可編輯專案、哪份是引擎接入資料。

## 常見問題與限制

- 缺圖先檢查 atlas 引用的所有 PNG 是否提供；Spine 版本選錯也會無法載入。
- Cocos 淡入淡出需節點具有 UIOpacity；事件播放需掛對應 SpineTimelineHook，單獨丟入 .anim 不足以完整接入。
- 舊「軟體閱讀說明」內的 C#／TS 是接入示意，不是完整正式播放器。
- Cocos 開關事件需要新版 `SpineTimelineHook.ts`，控制 Skeleton／Sprite 元件顯示；原生 `.anim` 動作事件仍以 T0 為主。次軌可由程式 JSON 或參考腳本接入。
- 初始顯示及開關可存檔／複製；自動保存容量不足會顯示提示，請手動保存。播放頭插入只順延該動畫軌，開關時間須自行核對。
- 錄影依瀏覽器編碼支援；保持分頁在前景，不保證固定逐幀編碼。

## 驗收檢查

重新開啟保存檔後核對角色、貼圖、動作與時間；影片及引擎匯出另行播放，不能只驗證網頁預覽。
