# 圖片中心點快速對位工具 1.0.1

用 Chrome／Edge 開啟 slot_symbol_center_align_tool.html，可離線使用。輸入透明 PNG，依視覺中心、底部或原畫布中心對齊，再輸出同畫布 PNG／ZIP。

底部對齊使用像素外框，padding=0 不再多移 1px。預覽保持原始寬高比。若有裁切警告，請增加輸出畫布或調整偏移；半透明發光是否納入邊界取決於 Alpha 門檻。

ZIP 標記 UTF-8 以保留中文檔名；同名輸出自動加序號。單圖上限8192px／3200萬來源像素，輸出整批限制6400萬像素，過量請分批。修改預覽／前綴不重算圖片，Alpha 門檻不變則重用邊界快取。

驗證：`node tests/regression.test.js`，包含底1px、裁切、非正方形預覽與 ZIP UTF-8 兩處標頭。未涵蓋所有瀏覽器下載政策及所有 PNG 解碼器。
