# 數字包圖工具｜使用指南

依本機現有程式與說明整理：2026-10-06（1.3.4）。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

把每個字元的 PNG 組成 BMFont 圖集，輸出給 Label／滾分工具。輸入各字元 PNG；需要千分位與小數時，記得準備逗號與小數點。

## 環境與啟動

將新版 `makefont.html` 單檔傳給同事即可，以 Chrome／Edge 開啟；ZIP 元件已內嵌，離線也能匯出，不必另外複製 `vendor`。不要使用檔名含 backup 或「舊版」資料夾中的 HTML。

## 操作步驟

1. 匯入各字元 PNG，在「確認圖片 → 字元配對」視窗核對每張圖。`dot.png`／`comma.png` 與 `uXXXX.png` 可辨識；`bU.png` 建議 B，`X2.png`／`X_a.png` 建議 X，但仍須確認圖片與大小寫。未知名稱需手動填一個字元，不再取檔名最後一字。
   - 同批重複字元：修改對應字元，或取消左側勾選略過其中一張。
   - 取代目前字形：明確勾選該列「取代現有字形」。未勾選不會覆蓋。
   - 按「確認匯入」才會加入圖片；取消或 Esc 保留現有字形。解碼失敗的圖片會列出錯誤並略過。
2. 設定輸出名稱、字級、行高、間距與匯出比例。先使用比例 1，確認整組字元都在圖集中。
3. 需要穩定滾分時，開啟等寬數字與 Cocos 固定數字格；檢查偏移、裁切與預覽，不要只觀察一串相同數字。
   - Cocos 垂直置中：開啟「整體置中」與「Cocos基線修正」，每字 Y／全域 Y 先用 0。依整組數字的可見邊界補償，保留標點的相對基線；負 yoffset 屬正常結果。
4. 匯出 ZIP，將同一批 PNG 與 FNT 一起交付，再到目標引擎測試。

## 輸出與保存

ZIP 內為 PNG 圖集與文字格式 `.fnt`。兩者要成對使用，不能將新版 FNT 配舊 PNG；重新命名圖集時也要同步 FNT 的 page 檔名。

## 常見問題與限制

- 一張圖片對應一個 Unicode 字元，不能填整個英文單字。若把整張 WIN 圖配給 W，之後輸入 W 會顯示整張圖，並不會自動拆成三個字母。
- 圖集最多 4096×4096；超限或比例無效時會阻擋匯出，降低比例或減少字元後重試。
- 固定數字格處理數字 advance／邊界一致性；窄字光學補寬是外觀選項，不是 Cocos 字級縮放。
- 網頁預覽不包含 Cocos SHRINK、材質或 Scene 重繪。寬度不足時，SHRINK 仍可能縮小整串文字。
- Cocos 的 Label 設水平／垂直 CENTER、Anchor 0.5／0.5。字形高於框時，置中後仍會超出上下邊緣；另調字級或行高，不要以移動 Node 代替字型偏移修正。升級 1.3.3 後需重新匯出 PNG／FNT，舊字型檔不會自動更新。

## 驗收檢查

以 `111111`、`888888`、`414141`、帶千分位及最長目標分數測試；確認缺字、字距與實際字級。Cocos 請用滾分 QA 插件再驗證。
