# Unity 快速建立 Spine 動畫 Prefab 工具｜使用指南

依本機現有程式與說明整理：2026-09-10。此文件是操作指南，不代表已驗證所有素材與執行環境。

## 用途與輸入

掃描 `*_SkeletonData`，產生 UI Spine Prefab、AnimatorController 及每個 Spine 動畫的 AnimationClip。可在所有輸出檔名前加共同機種名。

## 環境與啟動

將 `SpinePrefabBuilderWindow.cs` 放進 Unity 專案的 Editor 資料夾，保留原有 .meta。需 Spine.Unity、IGS_GAME_EX.SpineGraphicCtrl 與 SpineGraphicAnimationEventCtrl；不是不含公司元件的通用 Spine 插件。編譯後開啟「Tools → Spine → Spine Prefab Builder」。

## 操作步驟

1. 指定 Spine Folder、Prefab Output、Animation Output 與 SkeletonGraphic Material。預填的是原作者專案路徑，不存在時需自己指定。
2. 在「Machine Name / 機種名」填共同名稱，如 Game238；查看檔名預覽。留空沿用原名，設定依本機專案記住。
3. 決定 Scan subfolders、Ignored Folders、Skip 與 Overwrite。首次使用新輸出資料夾，避免誤改既有資產。
4. 按 Build，完成後將 Prefab 放進測試 Canvas，播放各 State，確認動畫事件能呼叫公司控制元件。

## 輸出與保存

以 Hero_SkeletonData／Idle、機種 Game238 為例：`Game238_Hero.prefab`、`Game238_Hero.controller`、`Game238_Hero_Idle.anim`。State 仍為 Hero_Idle，Spine 動畫仍為 Idle；不修改來源骨架。

## 常見問題與限制

- Skip 依加前綴後的檔名判斷；更換前綴會另建一組，不會改名／刪除舊輸出。覆寫關閉且遇到同名資產時會報錯。
- 缺少 IGS_GAME_EX 編譯錯誤需從原遊戲專案取得元件，不要用測試替身交付正式遊戲。
- 預設材質 GUID 不同時，手動指定正確 SkeletonGraphic 材質。
- 禁止檔名特殊字元及控制字元；前後空白忽略，尾端已有底線不重複補分隔。

## 驗收檢查

核對生成檔名、Prefab 引用及 Idle／Win 播放；92 項隔離測試使用 IGS 序列化替身，正式事件播放仍需在遊戲專案驗收。
